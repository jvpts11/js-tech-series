# O Gerenciador de Estilos

O Gerenciador de Estilos é a janela de configurações do CDE. Pressione o seu controle no Front Panel para abri-la. A janela se chama Gerenciador de Estilos - Cor, Gerenciador de Estilos - Plano de Fundo ou Gerenciador de Estilos - Áudio, dependendo da página.

Ela tem três páginas em uma faixa, e um clique em uma delas a abre. Cor é a paleta de que toda a área de trabalho é desenhada. Plano de Fundo é o padrão que cada espaço de trabalho usa. Áudio define o volume do sistema e para onde vai o seu som.

Tudo o mais que a máquina guarda sobre si mesma continua sendo definido no seu prompt, com o comando config.

## Cor

Cor tem oito paletas, com os nomes que elas têm: Default, Alpine, Broica, Charcoal, Desert, Neptune, SeaFoam e Urchin. A área de trabalho inteira muda para uma paleta assim que você a escolhe, então você a vê antes de mantê-la.

1. Abra a página Cor.
2. Escolha uma paleta. A área de trabalho muda para mostrá-la.
3. Pressione OK para mantê-la com a máquina.

OK mantém a paleta com a máquina. Cancelar, ou fechar a página de outra forma, restaura a paleta que a área de trabalho tinha quando a página foi aberta. Os botões na parte de baixo são Aplicar, OK e Cancelar.

## Plano de Fundo

O plano de fundo é o padrão atrás das janelas. Cada espaço de trabalho usa o seu, então os quatro espaços de trabalho podem parecer diferentes. Os seis padrões são Hatch, Pinstripe, Tiles, Weave, Dots e Plain.

1. Abra a página Plano de Fundo.
2. Escolha um padrão. Só a prévia muda.
3. Pressione Aplicar. O padrão vai para o espaço de trabalho indicado na página.

A página continua aberta depois de Aplicar, então você pode mudar o próximo espaço de trabalho.

## Áudio

Áudio tem uma escala de volume com o valor sobre o controle deslizante, e uma chave Silenciar. Tem duas saídas, cada uma um interruptor, e as duas podem estar ligadas. Uma saída sempre fica ligada: a última não pode ser desligada.

Nada é enviado à máquina enquanto você usa a página, e só OK envia a sua escolha a ela.

## Se algo der errado

> [!PROBLEM] Uma mudança de cor não se mantém.
> Você saiu da página Cor com Cancelar, ou fechando-a. Abra a página de novo e pressione OK.

> [!PROBLEM] Uma mudança de plano de fundo não se mantém.
> Pressione Aplicar para aquele espaço de trabalho.
