# System achievements

The Operating Systems tab rewards the systems you install and how you use them. Its root is the first boot of any system. Each system has a step of its own, and a few are hard ones, such as installing by hand or building from source.

Most install steps count the first boot: the first time an installed system starts through a monitor. The game marks the disk when it welcomes the system, so the mark stays with the disk. A live installer session does not count.

The Frames install steps hang from one another in the order of the editions, from Frames 95 to Frames 11, and the FreeBSD step hangs from the UNIX one.

## If something goes wrong

> [!PROBLEM] A boot achievement did not appear after a reinstall.
> The disk keeps the mark of its first welcome. Erase the disk, then install again, and the next boot counts. If the disk was not erased, the system was already welcomed.

> [!PROBLEM] Screenfetch on UNIX earns nothing.
> UNIX has no screenfetch package, and it is not one of the systems Professional Larper counts.
