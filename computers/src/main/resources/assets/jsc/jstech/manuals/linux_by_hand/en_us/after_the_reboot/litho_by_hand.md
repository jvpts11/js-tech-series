# Midsoft Lithography on a system built by hand

Midsoft Lithography is the program of a computer cabled to a Lithography Station from the Legacy on: it shows the station and writes the masks it exposes through ([](jsc:mask_writing)). A system built by hand has a terminal before it has a desktop, and there litho takes the whole screen: the arrows and [[Tab]] pick the mask, [[W]] writes it on the Mask Blank in the station, and [[F3]] gives the terminal back. Once a desktop is installed, it opens as a window too.

```command
id: jsc:command/linux/litho
```
