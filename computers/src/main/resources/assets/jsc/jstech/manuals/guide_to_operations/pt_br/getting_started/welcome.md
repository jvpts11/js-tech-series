# Bem-vindo ao J's Computers

J's Computers é sobre computadores. Mas o que é um computador aqui? Você pode esperar uma caixa que se coloca no lugar e se liga. Ele é isso, mas também é montado peça por peça, como um computador de verdade.

Computadores ligados por cabo de dados a um Mainframe ([](jsc:mainframes)) formam uma rede ([](jsc:what_a_network_is)). A rede guarda seus itens nos discos dela, move-os e fabrica o que você pedir.

Quando um computador liga, a primeira coisa que ele roda é o firmware ([](jsc:firmware)): o programa que verifica o hardware e encontra os discos. Depois ele passa o controle para um sistema operacional, o sistema que você usa no dia a dia.

Para montar um computador funcional você precisa de peças: uma placa-mãe, um processador (CPU), memória (RAM) e uma fonte de alimentação (PSU). Um disco guarda o sistema, e uma placa de vídeo (GPU) mostra a imagem no monitor. Cada peça tem a sua própria entrada, e [Montando seu primeiro computador](jsc:first_computer) as reúne.

Todas as peças deste mod vêm das abas criativas: o J's Computers não tem receitas de fabricação próprias. J's Computers reúne o que todas as eras têm em comum, e há uma aba para cada era, de J's Computers - Vintage até J's Computers - Advanced ([](jsc:eras)). Um modpack pode dar receitas ao mod, com o KubeJS ou um datapack; então o visualizador de receitas, o JEI ou o EMI, mostra como cada coisa é feita.

## Como ler este manual

Cada entrada começa em uma página própria. A fileira de itens sob o título de uma entrada, a placa de itens, é clicável: clique em um item para ir à página dele. Um número entre colchetes é um link para outra entrada.

Segure a tecla do manual sobre um item e o manual abre na página do item. A tecla do manual é [[M]], a menos que você a tenha alterado.

O botão Pesquisar encontra qualquer coisa no manual pelo nome. Uma pesquisa que não acha nada diz "Nada com esse nome".

Os botões Sumário, Índice e Glossário, e Voltar e Avançar, movem você pelo livro.

Este livro, o Guia de Operações, é um de sete livros. Os outros seis são o Kit de Recursos do Frames, A Referência de Mesa do Linux, Linux à Mão, O Manual do Daemon, Aprendendo IQL e O Livro do Sigma. Cada livro é um item da aba criativa do J's Computers, e a biblioteca ([](jsc:library)) diz o que cada um cobre.

> [!DEFINE] Firmware
> O programa na placa-mãe que inicia o computador. É a primeira coisa que roda quando você liga o computador.

> [!DEFINE] Sistema operacional
> O sistema em que um computador inicia, e sobre o qual roda todo programa. MC-DOS, Frames e as distribuições Linux são sistemas operacionais.

> [!DEFINE] Era
> Uma geração de hardware, como Vintage ou Standard. As peças de uma era são feitas para encaixar nas placas dessa era.
