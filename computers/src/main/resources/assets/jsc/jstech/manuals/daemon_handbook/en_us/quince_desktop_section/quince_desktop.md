# The menu bar, the Seeker and the Dock

Every Quince system starts at its desktop. Across the top is the menu bar: the fruit's menu at its left, then File, Edit and View. The fruit's menu opens About This Computer. On the classic systems it also holds a few programs, and the Special menu holds Empty Trash, Erase Disk, Set Startup, Restart and Shut Down. Erase Disk lists the volumes the system reads and asks before it erases the one you pick, formatting it again in its own file system; the startup disk is listed, and never chosen. Set Startup lists the volumes with a system on them, and the machine starts from the one you pick the next time it starts. From Quince OS X the fruit's menu holds System Preferences, Force Quit, Restart and Shut Down, and the Go and Window menus join the bar.

> [!DEFINE] Menu bar
> The bar across the top of a Quince desktop, with the fruit's menu at its left.

The disks and the Trash lie on the desktop. Double-click a disk to open it in the Seeker, Quince's file browser. Drag a file to the Trash to throw it away; emptying the Trash deletes it for good.

> [!DEFINE] Seeker
> Quince's file browser, where the disks, folders and files are opened.

From Quince OS X there is also the Dock along the bottom of the screen. It holds the programs you start most and every program that is open; click one to start it or bring it to the front.

> [!DEFINE] Dock
> The row of programs along the bottom of the screen, from Quince OS X.
