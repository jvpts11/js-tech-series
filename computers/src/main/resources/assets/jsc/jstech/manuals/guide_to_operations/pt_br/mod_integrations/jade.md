# Jade

O Jade é um mod que informa o que você está olhando. Aponte para um bloco, e uma pequena caixa mostra o nome dele e algumas linhas sobre ele. O Jade é opcional.

Quando o Jade está instalado, o plugin desta série para ele é ativado. Uma máquina que descreve o seu estado ao Jade acrescenta uma linha à caixa, como "Trabalhando: 40%" ou "Ocioso", como fazem as máquinas de processamento do J's Industrial.

Os blocos do J's Computers não descrevem a si mesmos ao Jade. Para eles, a caixa mostra apenas o nome do bloco e nada mais.

## Se algo der errado

> [!PROBLEM] O Jade mostra apenas um nome em um bloco do Computers.
> Isso é esperado por enquanto. Leia a página do próprio bloco neste guia, que explica a janela dele e as suas partes.
