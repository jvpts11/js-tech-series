# The Linux Desk Reference

This reference lies open beside the machine for anyone running Fedora, Debian, Ubuntu or Linux Mint: how to install them, how to work in the shell, the desktops and the editors, and where to look up a command.

Each command has a page of its own, the same page man and help show at the prompt.

The magnifier on the top edge finds anything by name, and the blocks down the edge of the right page each open a chapter.
