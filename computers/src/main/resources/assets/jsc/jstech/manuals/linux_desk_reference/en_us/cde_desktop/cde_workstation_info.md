# Workstation Info

Workstation Info tells you about the workstation you sit at: who is using it, the system it runs and the hardware under it. It is the CDE answer to This PC, and only CDE bundles it. Open it from the Applications subpanel, or from the Applications control.

Table: What it shows

| Group | Rows |
| --- | --- |
| Workstation | User Name, Host Name and Network, which reads "Not on a network" when there is none |
| System | Operating System, Architecture and Window System |
| Hardware | Processor, with its clock, Physical Memory, Memory in Use with a meter, Video Memory and System Disk |

Each figure is read when the window opens, and again every few seconds while the window stays open. So Memory in Use moves as the workstation works.

The Devices... button opens the Devices dialog. It shows one row for each port of the workstation: Video, then Audio, then the other ports by name. Each row shows what is plugged in, or "free". Select a device to Disable or Enable it. A disabled device is shown crossed out, in a quieter ink.

## If something goes wrong

> [!PROBLEM] Network reads "Not on a network".
> This workstation is not on a network. Connect it to one, as [](jsc:first_network) shows.
