# Jade

Jade is a mod that tells you what you are looking at. Point at a block, and a small box shows its name and a few lines about it. Jade is optional.

When Jade is installed, the plugin of this series for it switches on. A machine that describes its state to Jade adds a line to the box, such as "Working: 40%" or "Idle", as the processing machines of J's Industrial do.

The blocks of J's Computers do not describe themselves to Jade. For them, the box shows the block's name and nothing more.

## If something goes wrong

> [!PROBLEM] Jade shows only a name on a Computers block.
> That is expected for now. Read the block's own page in this guide, which explains its window and its parts.
