# O Software Manager

O Software Manager é a loja do Linux Mint, sobre o Mirror da rede. A sua página inicial põe um programa em destaque, um diferente a cada dia, lista as categorias e mostra os programas mais novos no Mirror. Ele não tem notas.

Table: As categorias

| Categoria | O que há nela |
| --- | --- |
| Acessórios, Gráficos, Internet, Escritório | As categorias do próprio Mint, como os nomes dizem. |
| Programação, Som e vídeo, Ferramentas, Jogos | O mesmo. |
| Rede | Os programas que trabalham a rede, e os seus serviços. |
| Desktops | As áreas de trabalho que este computador aceita. |

1. Abra o Software Manager pelo menu.
2. Escolha uma categoria, ou digite em Buscar e aperte Enter.
3. Abra um programa para ver a sua versão, o seu tamanho e o que ocupa na memória.
4. Aperte Instalar. Ele instala com o apt, como o Terminal faria.

As três linhas no canto de cima à direita listam o que você instalou.
