# keg, at the Terminal

With keg you install programs from the network's Mirror at the Terminal of Quince OS X, its Server and quinceOS. It came with the Standard era: on a computer of an older era, the Terminal has no keg command, and programs come from media.

> [!DEFINE] keg
> Quince's package manager, which installs the Mirror's programs at the Terminal.

```command
id: jsc:command/quince/keg
```
