# Nomes dos programas em cada área de trabalho

Cada área de trabalho chama os seus programas pelos próprios nomes. O programa é o mesmo: o Editor no KDE Plasma é o Kate, e é o mesmo editor de texto em qualquer área de trabalho. Encontre um programa na tabela, sob o nome que a sua área de trabalho mostra.

Table: Os nomes sob cada área de trabalho

| Programa | KDE Plasma | GNOME | Cinnamon | CDE |
| --- | --- | --- | --- | --- |
| Rede | Rede | Rede | Rede | Rede |
| Este Computador | Centro de Informações | Sobre | Informações do Sistema | não incluído |
| Configurações | Configurações do Sistema | Configurações | Configurações do Sistema | Gerenciador de Estilos |
| Arquivos | Dolphin | Arquivos | Nemo | Gerenciador de Arquivos |
| Editor | Kate | Editor de Texto | xed | Editor de Texto |
| Prompt de Comando | Konsole | Terminal | Terminal | Terminal |
| Monitor do Sistema | Monitor do Sistema | Monitor do Sistema | Monitor do Sistema | Medidor de Desempenho |
| Calculadora | KCalc | Calculadora | Calculadora | Calculadora |
| Gerenciador de Rede | Gerenciador de Rede | Gerenciador de Rede | Gerenciador de Rede | Gerenciador de Rede |
| Ajuda | Central de Ajuda | Ajuda | Ajuda | Visualizador de Ajuda |
| Informações da Estação de Trabalho | não incluído | não incluído | não incluído | Informações da Estação de Trabalho |

Um nome de produto, como Dolphin, Kate ou Nemo, é o mesmo em qualquer idioma. Um nome comum, como Editor de Texto ou Configurações do Sistema, é traduzido junto com o resto da tela.

Um programa mantém a sua própria janela, seja qual for o nome do seu atalho. Assim, um atalho renomeado ainda abre o mesmo programa.

O Gerenciador de Rede vem incluído em todas as áreas de trabalho, mas só aparece em um Mainframe. Em um computador que não é Mainframe, você não o vê em nenhum atalho.

## Se algo der errado

> [!PROBLEM] Você procura o Este Computador no CDE, e ele não está lá.
> O CDE não traz o Este Computador. Use as Informações da Estação de Trabalho, que respondem à mesma pergunta.

> [!PROBLEM] Você procura o Gerenciador de Rede, e ele não está no menu.
> Ele só aparece em um Mainframe. Procure-o em um Mainframe.
