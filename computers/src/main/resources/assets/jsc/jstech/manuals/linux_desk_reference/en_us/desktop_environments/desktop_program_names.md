# Program names under each desktop

Each desktop calls its programs by its own names. The program is the same one: the Editor on KDE Plasma is Kate, and it is the same text editor under any desktop. Find a program in the table under the name your desktop shows.

Table: The names under each desktop

| Program | KDE Plasma | GNOME | Cinnamon | CDE |
| --- | --- | --- | --- | --- |
| Network | Network | Network | Network | Network |
| This PC | Info Center | About | System Info | not bundled |
| Settings | System Settings | Settings | System Settings | Style Manager |
| Files | Dolphin | Files | Nemo | File Manager |
| Editor | Kate | Text Editor | xed | Text Editor |
| Command Prompt | Konsole | Terminal | Terminal | Terminal |
| System Monitor | System Monitor | System Monitor | System Monitor | Performance Meter |
| Calculator | KCalc | Calculator | Calculator | Calculator |
| Network Manager | Network Manager | Network Manager | Network Manager | Network Manager |
| Help | Help Center | Help | Help | Help Viewer |
| Workstation Info | not bundled | not bundled | not bundled | Workstation Info |

A product name, such as Dolphin, Kate or Nemo, reads the same in every language. A plain name, such as Text Editor or System Settings, is translated with the rest of the screen.

A program keeps its own window whatever its launcher is called. So a renamed launcher still opens the same program.

The Network Manager is bundled on every desktop, but it shows only on a Mainframe. On a computer that is not a Mainframe, you do not see it in any launcher.

## If something goes wrong

> [!PROBLEM] You look for This PC on CDE, and it is not there.
> CDE does not bundle This PC. Use Workstation Info, which answers the same question.

> [!PROBLEM] You look for the Network Manager, and it is not in the menu.
> It shows only on a Mainframe. Look for it on a Mainframe.
