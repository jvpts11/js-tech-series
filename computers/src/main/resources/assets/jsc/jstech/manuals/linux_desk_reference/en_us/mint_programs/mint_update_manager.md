# The Update Manager

The Update Manager lists every installed program the Mirror has a newer version of, each one ticked. While there is one, its shield is on the panel; press it to open the Update Manager.

1. Untick what you do not want, or press Clear and tick what you do.
2. Press Install Updates.

A program is installed at once. The desktop is installed the next time the desktop starts. Refresh asks the Mirror again.

## If something goes wrong

> [!PROBLEM] The Update Manager says no Mirror answers.
> The computer is not on a network whose Mainframe runs the Mirror.
