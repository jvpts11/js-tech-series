# GNOME

O GNOME é uma área de trabalho que roda no Linux e no FreeBSD, a partir do hardware Legacy. Seu pacote se chama gnome. Sua empresa é a GNOME Trust, uma software house do mundo do mod.

O GNOME também muda de aparência conforme a era. No hardware Legacy você vê o GNOME 1: uma moldura grossa em relevo, um título centralizado em roxo discreto, cinzas quentes e botões chanfrados e grossos. Na era Transition você vê o GNOME 2. A partir da era Standard você vê o próprio GNOME.

> [!DEFINE] Visão geral de atividades
> A visão em tela cheia da área de trabalho do GNOME, com um campo de busca, os espaços de trabalho e uma grade de todos os programas.

O GNOME não tem um menu Iniciar como tal. Seu painel é uma barra no topo da tela, com a Visão geral de atividades. Abra-a, e a visão geral cobre a área de trabalho com um campo de busca, a faixa de espaços de trabalho e uma grade de todos os programas.

Na era Transition, o GNOME 2 tem seu próprio menu, com seções chamadas Locais, Sistema, Preferências, Acessórios, Jogos, Internet e Ferramentas de sistema.

O GNOME dá aos seus programas nomes próprios, como mostra a tabela. Este Computador se chama Sobre.

Table: Nomes próprios do GNOME

| Programa | Nome no GNOME |
| --- | --- |
| Arquivos | Arquivos |
| Editor | Editor de Texto |
| Prompt de Comando | Terminal |
| Calculadora | Calculadora |
| Monitor do Sistema | Monitor do Sistema |
| Configurações | Configurações |
| Este Computador | Sobre |
| Ajuda | Ajuda |

Para instalá-lo, use a forma do seu sistema em [](jsc:install_a_desktop). No Fedora, é dnf install gnome. As linhas de inicialização mostram como "Iniciando o gerenciador de exibição do gnome".

## Se algo der errado

> [!PROBLEM] O gerenciador de pacotes diz "gnome precisa de hardware Legacy ou mais recente".
> O computador é da era Vintage. Use um computador Legacy ou um mais novo.

> [!PROBLEM] O gerenciador de pacotes diz "gnome já está na versão mais recente".
> Já está instalado. Uma área de trabalho instalada inicia na próxima inicialização, então reinicie o computador.
