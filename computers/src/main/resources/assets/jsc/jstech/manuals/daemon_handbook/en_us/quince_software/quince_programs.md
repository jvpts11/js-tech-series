# Quince's programs

Beside the programs every desktop has, Quince's systems come with programs of their own. You start each from the Dock, or from the Applications folder in the Seeker.

> [!DEFINE] qTunes
> The music player, from Quince OS 9. It plays the computer's songs with the same player every music program on the computer shares.

> [!DEFINE] Expedition
> The web browser, from Quince OS 9. The world has no web yet, so it shows a page that says so.

> [!DEFINE] Preview
> The picture viewer, from Quince OS X. Open a picture in the Seeker to see it.

> [!DEFINE] Quince Store
> The store, from Quince OS X. From the Standard era, it lists the programs the network's Mirror serves, and GET installs one, free.

> [!DEFINE] Server Admin
> On Quince OS X Server: the Mainframe's services, and buttons that stop and start the IQL Engine, the Mirror and the Automation Engine.

The classic systems take their programs from media only. The later ones take them from media too, and from the Standard era from the network's Mirror, with the Quince Store or with keg at the Terminal ([](jsc:quince_keg)).
