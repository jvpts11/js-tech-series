# Help and Support, and Get Help

Help is the window that reads the manuals of the series and the machine's own manual pages. Open it when you want to know what a command does or how a part works. Every desktop ships it, under a name that depends on the edition.

The contents hold the manuals of the series, with the Technical Reference first, as books of chapters, sections and entries. The commands of the machine are there too: each command's page is the one the machine prints for it at a terminal.

Table: Help on each edition

| Edition | Window title | Layout |
| --- | --- | --- |
| Frames 95 | Help Topics: Frames Help | Tabs for Contents, Index and Find |
| Frames XP | Help and Support Center | A Technical Reference pane, with Search, Home, Index, Favorites and History |
| Frames 7 | Frames Help and Support | Search Help and Browse Help |
| Frames 10 and Frames 11 | Get Help | A search box that says "Search the manuals and commands" |

## Searching

1. Type the word you want. The search field opens as you type.
2. Press [[Enter]] to run the search.
3. Read the result line: it gives the number of results and the word you searched for.

Links on a page lead to another page, and Back returns you to the page before.

## Keys

Table: Keys in Help

| Key | What it does |
| --- | --- |
| `Alt+Left` | Goes back to the page before. |
| `Alt+Right` | Goes forward again. |
| `Backspace` | Goes back, or deletes a letter while you type a search. |
| `Page Up, Page Down` | Scrolls the page. |
| `Enter` | Runs the search. On Frames 95 it displays the selected topic. |
| `Esc` | Stops typing the search. |

> [!DEFINE] Topic
> One page of help. On Frames 95 each topic opens in its own window.

The help is read at this machine, so the page for a command shows only the commands the machine has.

## If something goes wrong

> [!PROBLEM] The result line reads "Nothing in the manuals or the commands answers to", followed by your word.
> Try a shorter word, or the name of the command.

> [!PROBLEM] A command you expected is missing from the results.
> Look for the command on a machine that has it.
