# Frames 95

Frames 95 is the oldest edition and the first of the family. It needs a Legacy computer or newer, and it installs from a compact disc (CD) in the CD Drive.

Its look is the classic one: a grey taskbar with bevelled edges, and a Start list in a band down one side of the screen.

Frames 95 is cooperative. Each program keeps the processor until it gives it up, and the system does not take it back. Frames XP and the later editions are preemptive instead: the system takes the processor back when a program's turn is over.

> [!DEFINE] Cooperative multitasking
> A way of running programs in which each program keeps the processor until it gives it up.

## Installing Frames 95

1. Put the Frames 95 CD in the CD Drive, and start the computer from it. If the computer does not start from it, open the Boot Menu ([](jsc:boot_menu)).
2. Wait while the installer checks the computer: "Setup is checking this computer before it starts."
3. Choose a disk on the page "Choose a Disk".
4. Give the computer a name on the page "Computer Name".
5. Wait on the page "Copying Files" until the copy is done.
6. Wait for "Setup is finished."

The installer is a grey wizard, with a picture down one side, that moves through those pages in order.

Frames 95 names its help program Help. Its window is called "Help Topics: Frames Help" and has three tabs: Contents, Index and Find. A topic opens in a window called "Frames Help".

On this edition the Device Manager is called System, and it sits inside the System dialog. Its Task Manager is a Close Program box.

The visual effects page has the heading "Visual effects" and one check box: "Animate windows when minimizing and restoring".

When Frames 95 starts it plays "Frames 95 chimes", and when something goes wrong it plays "Frames 95 error". It plays no sound when a device connects or disconnects.

On a new computer, Frames 95 does not say "Hi.": it shows its own Welcome. When it starts, the screen shows a sky with the logo over the horizon, and a bar runs along the foot.

## If something goes wrong

> [!PROBLEM] The installer says "Frames 95 needs Legacy era hardware or newer; this machine is Vintage era."
> A Vintage computer cannot run Frames 95, so if you have one, use a Legacy computer or newer ([](jsc:eras)).

> [!PROBLEM] A program says "Automation Manager needs Frames XP or newer. This computer runs Frames 95."
> Run that program on a computer with Frames XP or newer ([](jsc:frames_xp)).
