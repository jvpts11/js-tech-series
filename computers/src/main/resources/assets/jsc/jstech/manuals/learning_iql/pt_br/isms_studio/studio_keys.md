# As teclas do estúdio

A maioria das ações tem uma tecla. O menu escreve essa tecla ao lado do item, e o estúdio responde à mesma tecla. A primeira tabela lista as teclas de arquivos e texto.

Quando você ler uma tecla escrita com sinal de mais, pressione as teclas juntas: [[Ctrl]]+[[Shift]]+[[S]] quer dizer segure Ctrl e Shift, depois pressione S.

Table: Atalhos para arquivos e texto

| Teclas | Item do menu e o que faz |
| --- | --- |
| `Ctrl+N` | Nova Consulta. Abre uma nova aba de consulta. |
| `Ctrl+O` | Abrir arquivo. Abre um arquivo no estúdio. |
| `Ctrl+F4` | Fechar. Fecha a aba de consulta atual. |
| `Ctrl+S` | Salvar. Salva a aba atual. |
| `Ctrl+Shift+S` | Salvar Tudo. Salva todas as abas. |
| `Ctrl+Z` | Desfazer. Desfaz a última alteração. |
| `Ctrl+Y` | Refazer. Faz a alteração de novo. |
| `Ctrl+X` | Recortar. |
| `Ctrl+C` | Copiar. |
| `Ctrl+V` | Colar. |
| `Ctrl+A` | Selecionar Tudo. |
| `Ctrl+F` | Localizar. Procura na aba. |
| `Ctrl+H` | Substituir. Procura na aba e troca o texto. |
| `Ctrl+G` | Ir Para a Linha. Vai para uma linha que você escolher. |
| `Ctrl+K` | Comentar / Descomentar. Transforma as linhas em comentários, ou de volta. |
| `Ctrl+Shift+U` | Converter em Maiúsculas. |
| `Ctrl+U` | Converter em Minúsculas. |
| `Ctrl+J` | Listar Membros. Oferece os nomes que o estúdio conhece. |
| `Ctrl+Space` | Completar Palavra. Oferece os nomes que o estúdio conhece. |

Table: Atalhos para execução e resultados

| Teclas | Item do menu e o que faz |
| --- | --- |
| `F5` | Executar. Roda o script inteiro. |
| `Ctrl+E` | Executar Seleção. Roda só o texto selecionado. Sem nada selecionado, roda a aba inteira. |
| `Alt+Break` | Cancelar Execução da Consulta. Para a consulta que está rodando. |
| `Ctrl+F5` | Analisar. Verifica a sintaxe sem executar nada. |
| `Ctrl+L` | Exibir Plano Estimado. Mostra o plano de uma instrução CRAFT sem executá-la. |
| `Ctrl+D` | Resultados em Grade. |
| `Ctrl+T` | Resultados em Texto. |
| `Ctrl+R` | Painel de Resultados. Mostra o painel de resultados. |
| `Ctrl+Shift+F` | Resultados em Arquivo. Salva os resultados como valores separados por vírgula. |
| `Ctrl+Shift+M` | Especificar Valores para Parâmetros de Modelo. Pede os valores dos espaços em branco de uma instrução. |

Table: Atalhos para as janelas e a ajuda

| Teclas | Item do menu e o que faz |
| --- | --- |
| `F8` | Pesquisador de Objetos. Abre a árvore da rede. |
| `F7` | Detalhes do Pesquisador de Objetos. Abre os detalhes do nó escolhido. |
| `F4` | Janela Propriedades. Mostra os dados do nó escolhido. |
| `Ctrl+Tab` | Próxima Guia. Vai para a próxima aba de consulta. |
| `Ctrl+Shift+Tab` | Guia Anterior. Vai para a aba de consulta anterior. |
| `F1` | Referência da IQL. Mostra a lista de instruções. |

A tecla Break às vezes vem impressa como Pause, e Alt+Pause também cancela uma consulta em execução. A página Atalhos do Teclado lista todas as teclas dos menus do estúdio. O menu Ajuda a abre.
