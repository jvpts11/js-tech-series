# The taskbar and its menu

The taskbar is the bar along the bottom of the screen. It holds the Start button, a button for every open program, and the status area at the right. Every Frames edition has a taskbar that is 24 pixels tall, but each one looks different.

Table: The taskbar of each edition

| Edition | What the bar looks like |
| --- | --- |
| Frames 95 | A grey bevelled bar. Start is at the left corner, each open program has a named button, and the status area is sunken at the right. |
| Frames XP | A blue gradient bar, with the green start pill and a quick launch strip beside it. |
| Frames 7 | A superbar of icons without titles. Each program is a glass button with its icon alone. A program with several windows shows the edge of a second pane behind its own. |
| Frames 10 | A dark bar: Start, the search box, the Task View button, one square for each program, then the status area and the Action Center button. |
| Frames 11 | A flat dark band. Start and the program icons sit together, centred. Each icon has a small mark that shows what its program is doing. The bar shows no window titles. |

## Clicking a program's button

What happens depends on the state of the program's windows.

Table: A click on a program's button

| You click | What happens |
| --- | --- |
| A program that is not open | It starts. |
| Its one window, in front | The window minimises, and goes down to the taskbar. |
| Its one window, minimised | The window comes back. |
| Its one window, behind others | The window comes to the front. |
| Several windows | A popup lists the windows of that program, so you can pick one. |

## The menu of an open program

Click a program's button with the right button to open its menu. The items you see depend on its windows.

Table: The menu of an open program

| Item | When it appears |
| --- | --- |
| Restore all | The program has several windows. |
| Restore | Its one window is minimised. |
| Bring to front | Its one window is not minimised. |
| Minimize all | The program has several windows. |
| Minimize | The program has one window. |
| Minimize others | The program is open. |
| Maximize | The program has one window. |
| Close all windows | The program has several windows. |
| Close | The program has one window. |
| Pin to taskbar, or Unpin from taskbar | Every Frames edition. It keeps the program's button on the bar, even when the program is closed. |

A closed program has a shorter menu: Open, and Unpin from taskbar if it is pinned.

## The menu of the empty bar

Right-click the empty part of the bar to open its menu. A line separates Show the Desktop from Task Manager.

Table: The menu of the empty bar

| Row | What it does |
| --- | --- |
| Cascade Windows | Arranges the windows in a cascade. |
| Show the Desktop | Minimises every window. |
| Task Manager | Opens the Task Manager. |

## The status area

At the right of the bar, the status area shows the network, the sound, the memory and the clock, and on some editions the day. The memory is random-access memory (RAM).

Table: The status area

| Shows | What it reads |
| --- | --- |
| The network | "Network connected" or "No network". |
| The memory | "RAM" and the amount in use. |
| The clock | The time: 24-hour by default, or 12-hour if you choose it on Personalize. |
| The day | On Frames 7 and Frames 10: the current in-game day, under the time, marked "Day". |

## The Task Manager

The [Task Manager](jsc:task_manager) lists the programs that are running. It also shows the processor, the memory, the network and the disks, and it ends a program that stops answering. Its pages are Applications, Processes, Performance, Networking, Services and Storage.

Frames 95 gives its Task Manager the shape of a close box. Frames XP and Frames 7 use tabs, and Frames 10 and Frames 11 use a modern shape with graphs.

> [!WARNING] Ending a program may lose unsaved work.

## If something goes wrong

> [!PROBLEM] A window has vanished from the screen.
> It is minimised. Click its button on the taskbar to bring it back.

> [!PROBLEM] A program has several windows, and you cannot tell which one you want.
> Click the program's button, then choose the window in the popup.

> [!DEFINE] Task View
> A view on Frames 10 that dims the desktop and shows every open window as a card.

> [!DEFINE] Action Center
> The dark pane of Frames 10 that lists the notices and holds the quick actions.
