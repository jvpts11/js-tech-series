# Installing a Quince system

Put the system's install medium in a drive linked to the computer, then start the installer from the computer's firmware, as for any system ([](jsc:installing)). Quince's installers look like Quince's desktop: a window on the grey or blue ground.

## The Quince System, from three floppies

The Quince System comes on three floppy disks: Install 1, System Tools and Utilities. Each floppy's tooltip says which of the three it is. Put the first in a Floppy Drive and press Install. When the installer has copied what is on it, it asks for the next one and puts the first out of the drive: put the next in, and the copy goes on by itself.

> [!DEFINE] Easy Install
> The Quince System's installer page, which installs the whole system onto the disk it shows.

## The others, from one disc

Quince OS 9, Quince OS X and its Server come on one CD (compact disc). Their installer goes through its pages in order: a welcome, what to read first, the license, the disk to install on and the kind of installation. Press Continue on each, Agree on the license, and Install once you have chosen the disk.

## quinceOS and its recovery

On a computer with one of Quince's chips, press Options on the start-up screen. It opens quinceOS's recovery, which offers three things: Reinstall quinceOS puts a fresh copy of the system on the disk, Disk Utility checks the startup disk with First Aid, and Startup Disk chooses the disk the computer starts from.

> [!DEFINE] Recovery
> The utilities quinceOS opens from the start-up screen's Options.

## If something goes wrong

> [!PROBLEM] The installer keeps asking for the next floppy.
> The floppy in the drive is not the one asked for. Put in the floppy the page names.

> [!PROBLEM] The copy stops with the medium taken out.
> Leave each medium in its drive until the installer asks for the next or the copy is done.
