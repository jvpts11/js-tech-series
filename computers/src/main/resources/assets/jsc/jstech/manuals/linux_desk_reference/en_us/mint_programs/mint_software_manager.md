# The Software Manager

The Software Manager is Linux Mint's store, on the network's Mirror. Its front page puts one program forward, a different one each day, lists the categories, and shows the newest programs on the Mirror. It has no ratings.

Table: The categories

| Category | What is in it |
| --- | --- |
| Accessories, Graphics, Internet, Office | Mint's own categories, as their names say. |
| Programming, Sound and video, System tools, Games | The same. |
| Network | The programs that work the network, and its services. |
| Desktops | The desktops this computer can take. |

1. Open the Software Manager from the menu.
2. Choose a category, or type in Search and press Enter.
3. Open a program to see its version, its size and what it takes in memory.
4. Press Install. It installs with apt, as the Terminal would.

The three lines at the top right list what you have installed.
