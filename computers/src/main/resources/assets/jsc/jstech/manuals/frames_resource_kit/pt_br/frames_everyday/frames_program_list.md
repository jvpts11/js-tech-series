# Os programas do Frames

Toda edição do Frames vem com o mesmo conjunto básico de programas, então as ferramentas de que você precisa estão em cada uma. São elas: Este Computador, Configurações, Arquivos, o Editor, o Prompt de Comando, o Monitor do Sistema, a Calculadora, o Gerenciador de Dispositivos, a Ajuda, e a Rede e o Gerenciador de Rede.

A maior parte do que você precisa já vem embutida, mas não tudo: o Virtual Studio pode ser instalado.

Algumas edições dão ao mesmo programa um nome próprio. A janela Arquivos se chama Explorador de Arquivos no Frames 10 e 11, e a janela Este Computador se chama Computador no Frames 7. A tabela mostra como os nomes de Arquivos, Este Computador e Ajuda mudam de edição para edição.

Table: Nomes dos programas por edição

| Edição | Arquivos | Este Computador | Ajuda |
| --- | --- | --- | --- |
| Frames 95 | Arquivos | Este Computador | Ajuda |
| Frames XP | Arquivos | Este Computador | Ajuda e Suporte |
| Frames 7 | Arquivos | Computador | Ajuda e Suporte |
| Frames 10 | Explorador de Arquivos | Este Computador | Obter Ajuda |
| Frames 11 | Explorador de Arquivos | Este Computador | Obter Ajuda |

Table: Nomes dos programas por edição, continuação

| Edição | Gerenciador de Dispositivos | Prompt de Comando |
| --- | --- | --- |
| Frames 95 | Sistema, em Propriedades do Sistema | Prompt de Comando |
| Frames XP | Gerenciador de Dispositivos | Prompt de Comando |
| Frames 7 | Gerenciador de Dispositivos | Prompt de Comando |
| Frames 10 | Gerenciador de Dispositivos | Prompt de Comando |
| Frames 11 | Gerenciador de Dispositivos | Megashell, no lançador |

No Frames 7 o Painel de Controle é o nome de Configurações. No Frames 11 o lançador chama o prompt de Megashell, que é o Prompt de Comando ([](jsc:command_prompt)) com outro nome.

> [!DEFINE] Programa
> Um conjunto de instruções que a máquina executa para você.

> [!DEFINE] Programa embutido
> Um programa que vem com a edição, sem etapa de instalação.

> [!DEFINE] Programa instalável
> Um programa que não está na máquina no início: você o instala a partir de uma mídia ou do Mirror.

## Se algo der errado

> [!PROBLEM] O Gerenciador de Tarefas não está na área de trabalho.
> Não é um programa de área de trabalho embutido. Clique com o botão direito na barra de tarefas e escolha Gerenciador de Tarefas ([](jsc:task_manager)).

> [!PROBLEM] O Virtual Studio não está na lista.
> É um programa instalável: instale-o primeiro ([](jsc:programs)).
