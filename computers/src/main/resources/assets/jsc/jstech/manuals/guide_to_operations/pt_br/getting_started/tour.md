# Um tour pelo J's Computers

Este mod tem muitas partes. Antes de escolher uma, convém ver o conjunto, desde os computadores que você monta até a rede que eles formam juntos.

Os computadores vêm em tipos. Um Computador Pessoal ([](jsc:personal_computers)) é o primeiro que você monta. Um Mainframe ([](jsc:mainframes)) comanda uma rede.

Outros são feitos para outras funções. Um Computador de Fabricação ([](jsc:crafting_computers)) carrega as placas de fabricação, e os servidores ficam em um rack de servidores ([](jsc:server_racks)). Um Computador de Gerenciamento de Cluster ([](jsc:cluster_management_computers)) ajuda você a operar muitas máquinas ao mesmo tempo.

Os computadores são montados com peças, uma por uma: uma placa-mãe, um processador, memória, uma placa de vídeo, um disco e uma fonte de alimentação. [Montando seu primeiro computador](jsc:first_computer) mostra como elas se encaixam.

Um computador mostra a imagem em um Monitor. Um monitor é ligado ao computador ficando encostado nele, ou por um [Cabo Periférico](jsc:peripheral_cables) quando fica mais longe.

Os drives leem as mídias de onde os sistemas são instalados ([](jsc:drives)). A Estação de Dock ([](jsc:dock_station)) lê pendrives USB. Impressoras imprimem, alto-falantes tocam som, e uma Redstone Interface ([](jsc:redstone_interfaces)) liga um computador à redstone.

Os computadores de uma mesma rede são ligados por cabo de dados ([](jsc:data_cables)). O J's Computers não tem canais nem sub-redes: uma rede é um Mainframe e os computadores dele. Roteadores e repetidores ([](jsc:routers)) ajudam a rede a chegar mais longe.

[Operações](jsc:what_operations_are) são tarefas que a rede executa, como selecionar, mover ou fabricar itens. Você as envia em IQL ([](jsc:iql)), a linguagem de consulta da rede.

Os itens ficam nos discos como dados ([](jsc:items_as_data)). Os barramentos ([](jsc:buses)) os movem para dentro e para fora, e a autofabricação ([](jsc:how_autocrafting_works)) fabrica o que você pede, a partir de padrões.

A ajuda de cada computador abre no livro do próprio sistema ([](jsc:help_on_a_computer)).
