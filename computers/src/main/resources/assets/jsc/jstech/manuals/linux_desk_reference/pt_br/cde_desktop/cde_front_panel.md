# O Front Panel e o EXIT

Cada controle do Front Panel mostra o seu nome quando você põe o ponteiro sobre ele, como "Gerenciador de Arquivos" ou "Lata de Lixo".

Table: Os controles

| Controle | O que faz |
| --- | --- |
| Relógio | Mostra a hora, com os seus ponteiros |
| Calendário | Mostra a data, com o dia na sua página |
| Gerenciador de Arquivos | Abre Arquivos, com um subpainel de Início, Área de Trabalho e cada mídia em uma unidade |
| Editor de Texto | Abre um subpainel com o título Aplicativos Pessoais: Editor de Texto, Prompt de Comando e Calculadora |
| Gerenciador de Estilos | Abre o Gerenciador de Estilos |
| Aplicativos | Abre um subpainel com o título Aplicativos: o Gerenciador de Aplicativos, o Monitor do Sistema e as Informações da Estação de Trabalho |
| Lata de Lixo | Abre a Lata de Lixo, e a sua imagem mostra se ela está vazia ou cheia |
| Visualizador de Ajuda | Abre o Visualizador de Ajuda |

O botão EXIT fica na extremidade direita da troca de espaço de trabalho, ao lado dos quatro espaços de trabalho. Não fica no canto direito do painel. Pressione-o para abrir a caixa de diálogo de saída, que tem três botões: Desligar, Reiniciar e Cancelar.

A caixa de diálogo diz quantos programas estão abertos. A contagem vem por extenso, então diz, por exemplo, "Três programas ainda estão abertos", seguido de "nesta estação de trabalho." A última linha avisa que o que não foi salvo será perdido.

Table: A caixa de diálogo de saída

| Palavras na caixa de diálogo | Quando ela as mostra |
| --- | --- |
| Nenhum programa está aberto | Nenhum programa roda |
| Um programa ainda está aberto | Um programa roda |
| Dois ou mais programas ainda estão abertos | Dois ou mais programas rodam, com o número por extenso |

## Se algo der errado

> [!PROBLEM] A caixa de diálogo diz que um programa ainda está aberto.
> Feche esse programa primeiro, para que nada se perca, e depois pressione EXIT.

> [!SEE] jsc:cde, jsc:cde_trash_can
