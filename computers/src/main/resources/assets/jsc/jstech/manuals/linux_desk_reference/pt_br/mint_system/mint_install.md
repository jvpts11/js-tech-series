# A sessão ao vivo e o instalador

O meio do Linux Mint inicia uma sessão ao vivo: a área de trabalho inteira, rodando de um disco na memória do computador. Você pode experimentar todo programa nela, e nada do que fizer fica no disco quando o computador reinicia.

> [!DEFINE] Sessão ao vivo
> O sistema rodando do seu meio e de um disco na memória, que não grava nada nos discos do computador.

Abra o Install Linux Mint na área de trabalho ao vivo para iniciar o instalador. Ele tem cinco telas e não pergunta idioma, teclado nem fuso horário: o jogo já os conhece.

> [!DEFINE] Install Linux Mint
> O ícone da área de trabalho ao vivo que abre o instalador por cima da sessão.

Table: As telas do instalador

| Tela | O que pergunta |
| --- | --- |
| Tipo de instalação | Instalar ao lado do sistema que está no disco, ou apagar o disco e instalar o Linux Mint sozinho. |
| Ao lado de outro sistema | Só aparece ao lado de um: como o disco é dividido entre os dois. |
| Quem é você? | O nome do computador. A senha espera as contas. |
| A cópia | Nada: mostra o que o Linux Mint tem enquanto copia. |
| Instalação concluída | Continuar testando, ou Reiniciar agora. |

O Linux Mint vai em ext4, com um swap do tamanho da memória do computador ao lado.

## Se algo der errado

> [!PROBLEM] O Install Linux Mint diz que o computador não aceita o sistema.
> O computador é anterior à era Standard, ou nenhum disco tem espaço para 12.288 MB.
