# A tour of J's Computers

This mod has many parts. Before you pick one, it helps to see the whole, from the computers you build to the network they make together.

The computers come in kinds. A Personal Computer ([](jsc:personal_computers)) is the one you build first. A Mainframe ([](jsc:mainframes)) directs a network.

Others are made for other jobs. A Crafting Computer ([](jsc:crafting_computers)) carries the crafting cards, and servers stand in a server rack ([](jsc:server_racks)). A Cluster Management Computer ([](jsc:cluster_management_computers)) helps you run many machines at once.

Computers are built from parts, one by one: a motherboard, a processor, memory, a graphics card, a disk and a power supply. [Building your first computer](jsc:first_computer) shows how they fit.

A computer shows its picture on a Monitor. A monitor is joined to a computer by standing right against it, or by a [Peripheral Cable](jsc:peripheral_cables) when it stands further away.

Drives read the media that systems are installed from ([](jsc:drives)). The Dock Station ([](jsc:dock_station)) reads USB sticks. Printers print, speakers play sound, and a Redstone Interface ([](jsc:redstone_interfaces)) links a computer to redstone.

Computers of one network are joined by data cable ([](jsc:data_cables)). J's Computers has no channels and no subnetworks at all: one network is one Mainframe and its computers. Routers and repeaters ([](jsc:routers)) help the network reach further.

[Operations](jsc:what_operations_are) are jobs the network does, such as selecting, moving or crafting items. You send them in IQL ([](jsc:iql)), the network's query language.

Items live on the disks as data ([](jsc:items_as_data)). Buses ([](jsc:buses)) move them in and out, and autocrafting ([](jsc:how_autocrafting_works)) crafts what you ask for, from patterns.

Each computer's help opens on the book of its own system ([](jsc:help_on_a_computer)).

## Where to start

1. Build one Personal Computer ([](jsc:first_computer)).
2. Turn it on ([](jsc:turning_on)).
3. Install a system on it ([](jsc:installing)).
4. Read what a network is ([](jsc:what_a_network_is)), then build your first one ([](jsc:first_network)).
