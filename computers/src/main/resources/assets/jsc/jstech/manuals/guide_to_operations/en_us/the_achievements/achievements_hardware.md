# Hardware achievements

The Hardware tab rewards building. Its root is the first step, and the others ask you to build working computers, fill racks, link monitors and run whole clusters. The table says what each one asks, and how the game checks it.

Table: The Hardware achievements

| Achievement | What it asks | How it is earned |
| --- | --- | --- |
| Hardware (root) | Get your hands on a computer. | You hold any computer item in your inventory: a computer case of any era, or a Mainframe. |
| PC Master Race (task) | Watch a computer pass its power-on self-test. | A computer finishes its power-on self-test (POST). |
| Have You Tried Turning It Off and On Again? (task) | Restart a running computer from its power menu. | You choose restart in the power menu of the desktop. Shutting down does not count. |
| Download More RAM (task) | Fill every RAM slot on a motherboard. | The random-access memory (RAM) installed fills every RAM slot of the motherboard, checked whenever the parts change. |
| The Save Icon (task) | Save a file to a floppy disk. | A file is written to a floppy disk in a media slot. |
| Battlestation (goal) | Link four monitors to one computer. | Four monitors are linked to the same computer; monitors merely placed near it do not count. |
| 640K Ought to Be Enough (task) | Build a working Vintage computer. | A computer of the Vintage era is built and its build is valid. |
| Party Like It's 1999 (task) | Build a working Legacy computer. | A computer of the Legacy era is built and its build is valid. |
| Moore's Law Isn't Dead (task) | Build a working Standard computer. | A computer of the Standard era is built and its build is valid. |
| Time Traveller (challenge) | Build a working computer of each of the five eras: Vintage, Legacy, Transition, Standard and Advanced. | Each of those five eras is built once, with a valid build. |
| Rack 'Em Up (goal) | Fill every unit of a Server Rack. | The rack's 8 units are all used, and a player filled the last one. |
| It's Just Someone Else's Computer (goal) | Form a datacenter section behind a Server Router. | A Server Router goes from no datacenter section to at least one. |
| Herding Cats (goal) | Run a whole cluster from a Cluster Management Computer. | You power on at least one node of the cluster, or you send an install to every node and it takes effect. |
| TOP500 (challenge) | Bring a supercomputer online: Supercomputer Racks on High Compute Cable. | The HBW Interface is on a network and has parallel crafts (more than zero). |
| The Megahertz Myth (task) | Build a working Transition computer. | A computer of the Transition era is built and its build is valid. |
| Hyperthreaded (task) | Build a working Advanced computer. | A computer of the Advanced era is built and its build is valid. |
| Magic Smoke (secret) | Burn a power supply. | A power supply of one of your machines wears out and fails. |
| CPU Over Temperature (secret) | Trip a computer's thermal protection. | One of your computers or racks reaches 100 °C and goes down. |
| Uninterruptible (task) | Ride out a power loss on a UPS. | A running machine stays on through a power loss on a UPS's battery. |
| A Pea-Sized Dot (task) | Fit a cooler with thermal paste. | A cooler of the Legacy or later, which is made with thermal paste, sits over a processor. |
| RGB Makes It Faster (goal) | Fill every fan slot of a case with Advanced case fans. | Every fan seat of the case holds an Advanced case fan. |
| N+1 (goal) | Keep a server running when one unit of its redundant power supply fails. | One unit of a redundant supply fails and the machine stays on. |
| It Just Works (task) | Build a working Quince machine. | A Quince machine is built and its build is valid. |
| Hard Copy (task) | Print a book on the Large Scale Printer. | The Large Scale Printer prints its first copy for you. |

Time Traveller asks for the five eras that have a build achievement: Vintage, Legacy, Transition, Standard and Advanced. The eras Exa and Singularity have no build achievement.

Each build hangs from the one before it: 640K Ought to Be Enough comes first, then Party Like It's 1999, then Moore's Law Isn't Dead, and Time Traveller hangs from the last.

## If something goes wrong

> [!PROBLEM] Rack 'Em Up does not appear after you fill a rack.
> The last unit must be placed by a player. A rack filled by other means does not earn it.

> [!PROBLEM] Battlestation does not appear with four monitors near the computer.
> Only monitors linked to the computer count. Link four monitors to it.

> [!PROBLEM] Time Traveller does not appear.
> It hangs from Moore's Law Isn't Dead, so earn that first.
