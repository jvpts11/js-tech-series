# The live session and the installer

Linux Mint's medium starts a live session: the whole desktop, running off a disk in the computer's memory. You can try every program in it, and nothing you do is kept on the disk when the computer starts over.

> [!DEFINE] Live session
> The system running from its medium and a disk in memory, which writes nothing to the computer's disks.

Open Install Linux Mint on the live desktop to start the installer. It has five screens, and it asks no language, keyboard or time zone: the game already knows them.

> [!DEFINE] Install Linux Mint
> The live desktop's icon that opens the installer over the session.

Table: The installer's screens

| Screen | What it asks |
| --- | --- |
| Installation type | To install beside the system on the disk, or to erase the disk and install Linux Mint alone. |
| Beside another system | Shown only beside one: how the disk is divided between the two. |
| Who are you? | The computer's name. The password waits for accounts. |
| The copy | Nothing: it shows what Linux Mint has while it copies. |
| Installation Complete | Continue Testing, or Restart Now. |

Linux Mint goes on ext4, with a swap as big as the computer's memory beside it.

## If something goes wrong

> [!PROBLEM] Install Linux Mint says the computer cannot take the system.
> The computer is older than the Standard era, or no disk has room for 12,288 MB.
