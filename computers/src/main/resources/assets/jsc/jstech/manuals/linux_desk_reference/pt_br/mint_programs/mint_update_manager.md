# O Update Manager

O Update Manager lista todo programa instalado de que o Mirror tem uma versão mais nova, cada um marcado. Enquanto houver um, o seu escudo fica no painel; aperte-o para abrir o Update Manager.

1. Desmarque o que não quer, ou aperte Limpar e marque o que quer.
2. Aperte Instalar.

Um programa é instalado na hora. A área de trabalho é instalada da próxima vez que ela iniciar. Atualizar pergunta ao Mirror de novo.

## Se algo der errado

> [!PROBLEM] O Update Manager diz que nenhum Mirror responde.
> O computador não está numa rede cujo Mainframe roda o Mirror.

> [!SEE] jsc:mint_software_manager
