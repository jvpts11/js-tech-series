# Datacenters

When you have many Server Racks, you group them into a datacenter. A Server Router does the grouping: it splits the racks into sections.

A section is the racks that one output face of a Server Router reaches, without crossing back through the router. The face joining the router to the network is its uplink, and the router detects it. Up to five sections hang off one router, one for each other face.

> [!DEFINE] Uplink
> The face of a Server Router that joins it to the network.

> [!DEFINE] Datacenter section
> The Server Racks that one output face of a Server Router reaches.

The label of a section shows its racks (R) and its servers (S). A section's default name is the router's name and its face.

A Server Router has one budget for all its sections together, and its era sets it: 4 Server Racks for the Legacy's, 8 for the Transition's, 16 for the Standard's and 32 for the Advanced's, counted section by section. Racks past the budget are counted as unmanaged, and the router shows its rack count in red when it goes over. The Vintage has no Server Router: its racks join the backbone directly.

More faces do not add budget. To manage more racks, use a second Server Router, which has a budget of its own, or one of a newer era.

## If something goes wrong

> [!PROBLEM] The rack count shows in red.
> The router manages as many racks as its era allows. Use a second Server Router, or one of a newer era, for the others.

> [!PROBLEM] A section has racks that are unmanaged.
> Take racks off that router, or put some on a second Server Router ([](jsc:server_router)).
