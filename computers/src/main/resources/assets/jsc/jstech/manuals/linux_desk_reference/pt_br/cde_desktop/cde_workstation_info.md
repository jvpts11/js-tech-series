# Informações da Estação de Trabalho

Informações da Estação de Trabalho mostra informações sobre a estação em que você está sentado: quem a está usando, o sistema que ela roda e o hardware por baixo. É a resposta do CDE para Este Computador, e só o CDE a traz. Abra-a pelo subpainel Aplicativos, ou pelo controle Aplicativos.

Table: O que mostra

| Grupo | Linhas |
| --- | --- |
| Estação de trabalho | Nome de Usuário, Nome do Host e Rede, que mostra "Não está em uma rede" quando não há nenhuma |
| Sistema | Sistema Operacional, Arquitetura e Sistema de Janelas |
| Hardware | Processador, com o seu clock, Memória Física, Memória em Uso com um medidor, Memória de Vídeo e Disco do Sistema |

Cada valor é lido quando a janela abre, e de novo a cada poucos segundos enquanto a janela continua aberta. Assim, Memória em Uso muda conforme a estação trabalha.

O botão Dispositivos... abre a caixa de diálogo Dispositivos. Ela mostra uma linha para cada porta da estação: Vídeo, depois Áudio, depois as outras portas pelo nome. Cada linha mostra o que está conectado, ou "livre". Selecione um dispositivo para Desativar ou Ativar. Um dispositivo desativado aparece riscado, em uma tinta mais discreta.

## Se algo der errado

> [!PROBLEM] Rede mostra "Não está em uma rede".
> Esta estação de trabalho não está em uma rede. Conecte-a a uma, como [](jsc:first_network) mostra.
