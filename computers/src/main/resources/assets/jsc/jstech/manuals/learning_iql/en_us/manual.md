# Learning IQL

IQL is the language you ask a network questions in and tell it what to do. This book teaches it from the first query to the last clause, with the engines that run it and the tools that write it.

The magnifier on the top edge finds anything by name, and the blocks down the edge of the right page each open a chapter.
