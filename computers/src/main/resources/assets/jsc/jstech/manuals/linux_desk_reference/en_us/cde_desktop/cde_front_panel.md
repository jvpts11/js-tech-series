# The Front Panel and EXIT

Each control of the Front Panel shows its name when you rest the pointer on it, such as "File Manager" or "Trash Can".

Table: The controls

| Control | What it does |
| --- | --- |
| Clock | Shows the time, with its hands |
| Calendar | Shows the date, with the day on its page |
| File Manager | Opens Files, with a subpanel of Home, Desktop and each medium in a drive |
| Text Editor | Opens a subpanel headed Personal Applications: Text Editor, Command Prompt and Calculator |
| Style Manager | Opens the Style Manager |
| Applications | Opens a subpanel headed Applications: the Application Manager, System Monitor and Workstation Info |
| Trash Can | Opens the Trash, and its picture shows whether it is empty or full |
| Help Viewer | Opens the Help Viewer |

The EXIT button sits at the right end of the workspace switch, beside the four workspaces. It is not at the far right of the panel. Press it to open the Exit dialog, which has three buttons: Shut Down, Restart and Cancel.

The dialog says how many programs are open. The count is spelled out, so it reads, for example, "Three programs are still open", followed by "on this workstation." The last line warns that what is not saved will be lost.

Table: The Exit dialog

| Words on the dialog | When it shows them |
| --- | --- |
| No program is open | No program runs |
| One program is still open | One program runs |
| Two or more programs are still open | Two or more programs run, with the number spelled out |

## If something goes wrong

> [!PROBLEM] The dialog says a program is still open.
> Close that program first, so that nothing is lost, then press EXIT.
