# When a Quince system crashes

A Quince system that crashes stops on its page and stays there until you restart the computer. Press Restart on the bomb, or any key; the computer then starts over from its self-test. What was running is lost.

The classic systems show the bomb: a box with a bomb and the words "Sorry, a system error occurred.", with the error's number below. Quince OS 9 also names the program that was running. The later systems show a grey page that asks you to restart, in English, French, German and Spanish.

> [!DEFINE] Bomb
> The box the classic systems crash onto, with the error's number.

Table: The bomb's numbers

| Number | What went wrong |
| --- | --- |
| `25` | The memory ran out. |
| `02` | A part was taken out from under a running program. |
| `01` | Anything else. |
