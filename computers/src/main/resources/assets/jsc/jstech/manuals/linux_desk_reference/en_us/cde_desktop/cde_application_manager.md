# The Application Manager

The Application Manager is CDE's program list. It groups the programs in folders, so you find a program by its group. Open it from the Applications control on the Front Panel, or from the first row of the Applications subpanel.

Table: The groups

| Group | What it holds |
| --- | --- |
| Desktop_Apps | Files, Editor, Command Prompt, Calculator and Settings |
| Desktop_Tools | Every program named in no other group, such as one someone else wrote. |
| Network | Network, Network Manager, ISMS, NextGre Studio, Prophet Console, Gateway Manager, Remote Control, Cluster Manager, Crafting Manager, Storage Insights, Craft Planner, Automation Manager and Pattern Studio |
| Games | Minesweeper |

A group is drawn only when it holds a program. Its status line says how many programs it holds, such as "Games, 1 program". A double click on a group opens it in its own window, and a double click on a program starts it.

The window reads the desktop each time it draws, so a program you install while the window is open appears at once, without a refresh.

## If something goes wrong

> [!PROBLEM] A group you expect is not drawn.
> A group with no program in it is not drawn. Install a program for it.

> [!PROBLEM] A program is not in the group you expect.
> A program named in no other group lands in Desktop_Tools. Look there.
