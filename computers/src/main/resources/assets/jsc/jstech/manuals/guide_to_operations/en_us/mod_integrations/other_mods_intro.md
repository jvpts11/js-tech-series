# Other mods

Some of the mods you play with can add to J's Computers. Six of them each add a feature when they are installed: ComputerCraft, JEI, EMI, Mekanism, Jade and Create.

Each of them is optional. Without one of these mods, its feature is missing, and the rest of J's Computers works as before.

ComputerCraft computers run programs written in Lua. The Network Gateway is the bridge between those computers and yours ([](jsc:network_gateway)). The section after this one explains the Gateway in detail.

> [!DEFINE] Network Gateway
> A block that links one of your computers to ComputerCraft computers.

> [!DEFINE] ComputerCraft
> The mod CC: Tweaked, which adds programmable computers to Minecraft.

> [!DEFINE] Lua
> The programming language in which the programs of ComputerCraft computers are written.
