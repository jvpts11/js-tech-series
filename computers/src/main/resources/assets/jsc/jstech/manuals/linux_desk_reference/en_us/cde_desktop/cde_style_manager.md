# The Style Manager

The Style Manager is the settings window of CDE. Press its control on the Front Panel to open it. Its window is called Style Manager - Color, Style Manager - Backdrop or Style Manager - Audio, depending on the page.

It has three pages in a strip, and a click on one opens it. Color is the palette the whole desktop is drawn from. Backdrop is the pattern each workspace wears. Audio sets the system's volume and where its sound goes.

Everything else the machine keeps about itself is still set at its prompt, with the config command.

## Color

Color has eight palettes, under the names they have: Default, Alpine, Broica, Charcoal, Desert, Neptune, SeaFoam and Urchin. The whole desktop changes to a palette as soon as you pick it, so you see it before you keep it.

1. Open the Color page.
2. Pick a palette. The desktop changes to show it.
3. Press OK to keep it with the machine.

OK keeps the palette with the machine. Cancel, or closing the page any other way, puts back the palette the desktop had when the page opened. The buttons along the foot are Apply, OK and Cancel.

## Backdrop

The backdrop is the pattern behind the windows. Each workspace wears its own, so the four workspaces can look different. The six patterns are Hatch, Pinstripe, Tiles, Weave, Dots and Plain.

1. Open the Backdrop page.
2. Pick a pattern. Only the preview changes.
3. Press Apply. The pattern goes on the workspace named on the page.

The page stays open after Apply, so you can change the next workspace.

## Audio

Audio has a volume scale with its value over the slider, and a Mute switch. It has two outputs, each a toggle, and both may be on. One output always stays on: the last one cannot be turned off.

Nothing is sent to the machine while you work the page, and only OK sends your choice to it.

## If something goes wrong

> [!PROBLEM] A colour change does not stay.
> You left the Color page with Cancel, or by closing it. Open the page again and press OK.

> [!PROBLEM] A backdrop change does not stay.
> Press Apply for that workspace.
