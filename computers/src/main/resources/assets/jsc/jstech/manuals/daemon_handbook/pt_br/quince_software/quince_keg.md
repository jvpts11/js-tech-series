# O keg, no Terminal

Com o keg você instala programas do Mirror da rede no Terminal do Quince OS X, do seu Server e do quinceOS. Ele veio com a era Standard: num computador de uma era mais antiga, o Terminal não tem o comando keg, e os programas vêm de mídias.

> [!DEFINE] keg
> O gerenciador de pacotes da Quince, que instala os programas do Mirror no Terminal.

```command
id: jsc:command/quince/keg
```

> [!SEE] jsc:quince_programs, jsc:mirror
