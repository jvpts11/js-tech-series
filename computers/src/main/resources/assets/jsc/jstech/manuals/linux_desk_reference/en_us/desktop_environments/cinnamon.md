# Cinnamon

Cinnamon is a desktop from Spearmint Linux, a software house of the mod's world. It runs on Linux and FreeBSD, and it needs Standard hardware or later. It is a later desktop, so no older computer can run it.

Cinnamon has one look, on every computer it runs on, so you never meet an older face. Its package is named cinnamon.

Its menu has three parts: a left rail of favourites, then the categories, then the list of programs in the chosen category. The categories are System, Accessories, Office and Preferences.

Table: The categories

| Category | What it holds |
| --- | --- |
| System | Files, This PC, the System Monitor, the Command Prompt, the Network, Help and the other system tools |
| Accessories | Everything else: the Calculator, the editors, the games |
| Office | Exceed, the Workshop, the Crafting Manager, the Pattern Studio, the Craft Planner, the Storage Insights and the Automation Manager |
| Preferences | Settings |

Cinnamon gives its programs its own names: Nemo for Files, xed for the Editor, Terminal for the Command Prompt, System Settings for Settings and System Info for This PC. The full list is in [](jsc:desktop_program_names).

To install it, use the form for your system in [](jsc:install_a_desktop). The boot lines show it as "Starting cinnamon Display Manager".

## If something goes wrong

> [!PROBLEM] The package manager says "cinnamon needs Standard hardware or later".
> The computer is older than Standard. Use a Standard computer or a newer one.

> [!PROBLEM] The installer does not offer Cinnamon on a Legacy computer.
> On a Legacy computer, choose another desktop, because Cinnamon is offered only on Standard hardware or later.
