# The programs of Frames

Every Frames edition comes with the same core set of programs, so the tools you need are on each one. They are This PC, Settings, Files, the Editor, the Command Prompt, System Monitor, Calculator, the Device Manager, Help, and the Network and the Network Manager.

Most of what you need is built in, but not all of it: Virtual Studio is installable.

Some editions give the same program a name of their own. The Files window is called File Explorer on Frames 10 and 11, and the This PC window is called Computer on Frames 7. The table shows how the names of Files, This PC and Help change from edition to edition.

Table: Program names by edition

| Edition | Files | This PC | Help |
| --- | --- | --- | --- |
| Frames 95 | Files | This PC | Help |
| Frames XP | Files | This PC | Help and Support |
| Frames 7 | Files | Computer | Help and Support |
| Frames 10 | File Explorer | This PC | Get Help |
| Frames 11 | File Explorer | This PC | Get Help |

Table: Program names by edition, continued

| Edition | Device Manager | Command Prompt |
| --- | --- | --- |
| Frames 95 | System, in System Properties | Command Prompt |
| Frames XP | Device Manager | Command Prompt |
| Frames 7 | Device Manager | Command Prompt |
| Frames 10 | Device Manager | Command Prompt |
| Frames 11 | Device Manager | Megashell, in the launcher |

On Frames 7 the Control Panel is the name of Settings. On Frames 11 the launcher calls the prompt Megashell, which is the Command Prompt ([](jsc:command_prompt)) under another name.

> [!DEFINE] Program
> A set of instructions the machine runs for you.

> [!DEFINE] Built-in program
> A program that comes with the edition, with no install step.

> [!DEFINE] Installable program
> A program that is not on the machine at first: you install it from a medium or from the Mirror.

## If something goes wrong

> [!PROBLEM] The Task Manager is not on the desktop.
> It is not a bundled desktop program. Right-click the taskbar and choose Task Manager ([](jsc:task_manager)).

> [!PROBLEM] Virtual Studio is not in the list.
> It is an installable program: install it first ([](jsc:programs)).
