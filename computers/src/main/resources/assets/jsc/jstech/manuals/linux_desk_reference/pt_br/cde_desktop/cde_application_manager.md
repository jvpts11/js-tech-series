# O Gerenciador de Aplicativos

O Gerenciador de Aplicativos é a lista de programas da CDE. Ele agrupa os programas em pastas, para que você encontre um programa pelo seu grupo. Abra-o pelo controle Aplicativos no Front Panel, ou pela primeira linha do subpainel Aplicativos.

Table: Os grupos

| Grupo | O que contém |
| --- | --- |
| Desktop_Apps | Arquivos, Editor, Prompt de Comando, Calculadora e Configurações |
| Desktop_Tools | Todo programa que não consta em nenhum outro grupo, como um escrito por outra pessoa. |
| Rede | Rede, Gerenciador de Rede, ISMS, NextGre Studio, Prophet Console, Gerenciador de Gateway, Controle Remoto, Gerenciador de Cluster, Gerenciador de Fabricação, Análise de Armazenamento, Planejador de Fabricação, Gerenciador de Automação e Pattern Studio |
| Jogos | Campo Minado |

Um grupo só é desenhado quando tem um programa. A sua linha de status diz quantos programas ele tem, como "Jogos, 1 programa". Um duplo clique em um grupo o abre na sua própria janela, e um duplo clique em um programa o inicia.

A janela lê a área de trabalho cada vez que se desenha, então um programa que você instala enquanto a janela está aberta aparece na hora, sem atualizar.

## Se algo der errado

> [!PROBLEM] Um grupo que você espera não é desenhado.
> Um grupo sem nenhum programa não é desenhado. Instale um programa para ele.

> [!PROBLEM] Um programa não está no grupo que você espera.
> Um programa que não está em nenhum outro grupo vai para o Desktop_Tools. Procure lá.
