# GNOME

GNOME is a desktop that runs on Linux and FreeBSD, from Legacy hardware on. Its package is named gnome. Its house is the GNOME Trust, a software house of the mod's world.

GNOME changes its face with the era too. On Legacy hardware you see GNOME 1: a thick frame in relief, a centred title in muted purple, warm greys and chunky bevelled studs. On Transition you see GNOME 2. From the Standard on you see GNOME itself.

> [!DEFINE] Activities overview
> GNOME's full-screen view of the desktop, with a search field, the workspaces and a grid of every program.

GNOME has no start menu as such. Its panel is a bar along the top of the screen, with the Activities overview. Open it, and the overview covers the desktop with a search field, the workspace strip and a grid of every program.

On Transition, GNOME 2 has its own menu, with sections named Places, System, Preferences, Accessories, Games, Internet and System Tools.

GNOME gives its programs its own names, as the table shows. This PC is called About.

Table: GNOME's own names

To install it, use the form for your system in [](jsc:install_a_desktop). On Fedora, that is dnf install gnome. The boot lines show it as "Starting gnome Display Manager".

## If something goes wrong

> [!PROBLEM] The package manager says "gnome needs Legacy hardware or later".
> The computer is a Vintage one. Use a Legacy computer or a newer one.

> [!PROBLEM] The package manager says "gnome is already the newest version".
> It is installed already. A desktop that is installed starts at the next boot, so restart the computer.
