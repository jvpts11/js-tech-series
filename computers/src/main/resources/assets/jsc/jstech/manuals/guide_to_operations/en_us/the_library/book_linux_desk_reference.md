# The Linux Desk Reference

The Linux Desk Reference lies open beside the machine. It is written for the command line first: you read what to type, what the system answers, and what each step does. It covers Fedora, Debian and Ubuntu, the three distributions you install with a guide.

Its chapters are Fedora, Debian and Ubuntu, with the installs, the first boot, apt and dnf, and the four UNIX chapters it shares with the other books: The shell, The desktops, Editors at the terminal and Finding help.

Its help opens first for Ubuntu, Debian and Fedora, when you installed them with a guide. Start with [Distributions](jsc:distributions).

## If something goes wrong

> [!PROBLEM] You do not have this book.
> Take it from the creative tab J's Computers, among the programs, beside the Guide.
