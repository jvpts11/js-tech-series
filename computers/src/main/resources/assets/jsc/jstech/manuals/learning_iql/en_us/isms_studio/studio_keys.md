# Its keys

Most actions have a key. The menu writes that key beside the item, and the studio answers to the same key. The first table lists the keys for files and text.

When you read a key written with a plus sign, press the keys together: [[Ctrl]]+[[Shift]]+[[S]] means hold Ctrl and Shift, then press S.

Table: Keys for files and text

| Keys | Menu item and what it does |
| --- | --- |
| `Ctrl+N` | New Query. Opens a new query tab. |
| `Ctrl+O` | Open File. Opens a file in the studio. |
| `Ctrl+F4` | Close. Closes the current query tab. |
| `Ctrl+S` | Save. Saves the current tab. |
| `Ctrl+Shift+S` | Save All. Saves every tab. |
| `Ctrl+Z` | Undo. Takes back the last change. |
| `Ctrl+Y` | Redo. Makes the change again. |
| `Ctrl+X` | Cut. |
| `Ctrl+C` | Copy. |
| `Ctrl+V` | Paste. |
| `Ctrl+A` | Select All. |
| `Ctrl+F` | Find. Searches the tab. |
| `Ctrl+H` | Replace. Searches the tab and replaces the text. |
| `Ctrl+G` | Go To Line. Moves to a line you choose. |
| `Ctrl+K` | Comment / Uncomment. Turns the lines into comments, or back. |
| `Ctrl+Shift+U` | Make Uppercase. |
| `Ctrl+U` | Make Lowercase. |
| `Ctrl+J` | List Members. Offers the names the studio knows. |
| `Ctrl+Space` | Complete Word. Offers the names the studio knows. |

Table: Keys for running and results

| Keys | Menu item and what it does |
| --- | --- |
| `F5` | Execute. Runs the whole script. |
| `Ctrl+E` | Execute Selection. Runs only the selected text. With nothing selected, it runs the whole tab. |
| `Alt+Break` | Cancel Executing Query. Stops the query that is running. |
| `Ctrl+F5` | Parse. Checks the syntax without running anything. |
| `Ctrl+L` | Display Estimated Plan. Shows the plan of a CRAFT statement without running it. |
| `Ctrl+D` | Results to Grid. |
| `Ctrl+T` | Results to Text. |
| `Ctrl+R` | Results Pane. Shows the results pane. |
| `Ctrl+Shift+F` | Results to File. Saves the results as comma-separated values. |
| `Ctrl+Shift+M` | Specify Values for Template Parameters. Asks for the values of a statement's blanks. |

Table: Keys for the windows and help

| Keys | Menu item and what it does |
| --- | --- |
| `F8` | Object Explorer. Opens the tree of the network. |
| `F7` | Object Explorer Details. Opens the details of the picked node. |
| `F4` | Properties Window. Shows the facts of the picked node. |
| `Ctrl+Tab` | Next Tab. Moves to the next query tab. |
| `Ctrl+Shift+Tab` | Previous Tab. Moves to the previous query tab. |
| `F1` | IQL Reference. Shows the list of statements. |

The Break key is sometimes printed as Pause, and Alt+Pause also cancels a running query. The Keyboard Shortcuts page lists every key of the studio's menus. The Help menu opens it.
