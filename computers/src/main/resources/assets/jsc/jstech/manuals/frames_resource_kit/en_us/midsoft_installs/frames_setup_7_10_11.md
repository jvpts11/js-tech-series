# Setting up Frames 7, 10 and 11

Frames 7 comes on a DVD, which you read in a DVD Drive. Frames 10 and Frames 11 come on a USB stick, which you plug into a Dock Station joined to the computer ([](jsc:dock_station)).

Each of the three has its own setup window, in the look of its era. They ask for the same things, a disk, a name and a copy, but in a different order and with different words.

## Frames 7

On Frames 7, the setup is a glass window titled "Install Frames". Its welcome page has one large "Install now" button.

1. Put the Frames 7 DVD in a DVD Drive that is joined to the computer.
2. Turn the computer on, and choose "Frames 7 installer" in the firmware.
3. Follow the pages in the table below, in the order the table gives them.

Table: The pages of Frames 7

| Page | What it shows |
| --- | --- |
| Welcome | One large "Install now" button. |
| Disk | "Where do you want to install Frames?" |
| Copy | "Installing Frames...", with the steps Copying Frames files, Expanding Frames files, Installing features, Installing updates and Completing installation. |
| Name | "Choose a name for your computer to distinguish it on the network." |
| Done | "Setup is finished." |

## Frames 10

Frames 10 has its own look, titled "Frames Setup". Its name page takes the whole screen.

Table: The pages of Frames 10

| Page | What it shows |
| --- | --- |
| Welcome | One large "Install now" button. |
| Disk | "Where do you want to install Frames?" |
| Copy | "Installing Frames", with the steps Copying Frames files, Getting files ready for installation, Installing features, Installing updates and Finishing up. |
| Name | "Who's going to use this PC?" The answer becomes the computer's name. |
| Done | "Setup is finished." |

## Frames 11

Frames 11 uses cards, in a window titled "Frames 11 Setup". Each card has its own buttons: Next and Back, and Erase disk on the disk page. The welcome card asks nothing: it has one button, Install now.

Table: The pages of Frames 11

| Page | What it shows |
| --- | --- |
| Welcome | One large "Install now" button, which asks nothing. |
| Disk | "Where do you want to install Frames 11?" |
| Name | "Name this PC". |
| Copy | "Installing Frames 11", with the steps Copying files, Creating the system folders, Adding the built-in programs and Setting up the boot entry. |
| Done | "Setup is finished." The button on this card is Restart. |

## The USB stick

The USB stick holds the system for Frames 10 and 11. It does not go into the computer: it goes into the USB port of a Dock Station, and the Dock Station must be joined to the computer. The stick's tooltip says "Plug into a linked Dock Station", and a hint says to run the setup program or to install from This PC.

1. Plug the stick into the USB port of a Dock Station that is joined to the computer.
2. Turn the computer on, and choose "Frames 10 installer" or "Frames 11 installer" in the firmware.
3. Follow the pages of your edition, as the tables above show them.

## If something goes wrong

> [!PROBLEM] The firmware does not offer the installer, and says: "No installation medium is in a drive linked to this machine."
> The stick is not in a Dock Station, or the Dock Station is not joined to the computer. Plug the stick in, and join the Dock Station ([](jsc:peripheral_cables)).

> [!PROBLEM] The disk page says: "No room here. Erase this disk, or choose another."
> Choose another disk with room, or erase this disk as described in the Frames 95 section ([](jsc:frames_setup_95_xp)).

> [!PROBLEM] The copy stops and says: "The medium was taken out before the system was written."
> Put the stick back in the Dock Station, start the setup again, and leave the stick in until the copy ends.
