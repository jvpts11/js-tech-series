# Frames XP

Frames XP is the second edition. It keeps the Legacy era, so a Legacy computer runs it, but it asks for far more room: its footprint is 1,536 MB, which is 96 items on a Legacy disk.

Frames XP is preemptive. The system takes the processor from a program when that program's turn is over, so one program does not hold the processor from the others.

> [!DEFINE] Preemptive multitasking
> A way of running programs in which the system takes the processor from a program when its turn is over.

Its look is the Luna look: a taskbar along the bottom of the screen and a Start menu in two columns.

## Installing Frames XP

1. Put the Frames XP CD in the CD Drive, and start the computer from it. If the computer does not start from it, open the Boot Menu ([](jsc:boot_menu)).
2. On the page "The following list shows the disks on this computer.", choose the disk.
3. Wait on the copying page, which says "Please wait while Setup copies files to the disk."
4. Give the computer a name on the page "Computer Name", where the side panel shows "Collecting information".
5. Wait while the side panel shows "Installing Frames" and then "Finalizing installation".
6. Wait for "Setup is finished."

The copy happens in two stages: the first before the name, and the second after it. The installer changes shape between them, and the second stage shows its steps in a side panel.

Frames XP calls its help program Help and Support. Its window is the Help and Support Center, with one pane called "Technical Reference".

Its Task Manager has four tabs: Applications, Processes, Performance and Networking, with a menu bar and a status bar. Its Device Manager is a console window: the views are in the View menu, and a right-click opens its actions.

The visual effects settings are in Performance Options, which you reach from System. The page has the heading "Visual effects", four presets, and four checks. The presets are "Let Frames choose what's best for my computer", "Adjust for best appearance", "Adjust for best performance" and "Custom:".

The checks are "Animate windows when minimizing and maximizing", "Fade or slide menus into view", "Fade or slide ToolTips into view" and "Use drop shadows for icon labels on the desktop".

On a new computer, Frames XP greets you with a balloon notice, a small pop-up from the taskbar area, instead of a window. It plays "Frames XP chimes" when it starts and "Frames XP error" when something goes wrong.

Its splash screen is black, with the logo above the middle and three blocks in a trough.

## If something goes wrong

> [!PROBLEM] The installer says "Frames XP needs Legacy era hardware or newer; this machine is Vintage era."
> A Vintage computer cannot run Frames XP. Use a Legacy computer or newer ([](jsc:eras)).

> [!PROBLEM] The installer says that the target disk has no room for Frames XP, and gives the megabytes it needs.
> Use a Legacy disk with room for 96 items, which is what Frames XP takes.
