# Os programas da Quince

Além dos programas que toda área de trabalho tem, os sistemas da Quince trazem programas próprios. Você abre cada um pelo Dock, ou pela pasta Aplicativos no Seeker.

> [!DEFINE] qTunes
> O tocador de música, a partir do Quince OS 9. Toca as músicas do computador com o mesmo tocador que todo programa de música do computador compartilha.

> [!DEFINE] Expedition
> O navegador web, a partir do Quince OS 9. O mundo ainda não tem web, então ele mostra uma página que diz isso.

> [!DEFINE] Preview
> O visualizador de imagens, a partir do Quince OS X. Abra uma imagem no Seeker para vê-la.

> [!DEFINE] Quince Store
> A loja, a partir do Quince OS X. A partir da era Standard, lista os programas que o Mirror da rede serve, e OBTER instala um, de graça.

> [!DEFINE] Server Admin
> No Quince OS X Server: os serviços do Mainframe, e botões que param e iniciam o IQL Engine, o Mirror e o Automation Engine.

Os sistemas clássicos tiram os seus programas só de mídias. Os mais novos também os tiram de mídias e, a partir da era Standard, do Mirror da rede, com a Quince Store ou com o keg no Terminal ([](jsc:quince_keg)).
