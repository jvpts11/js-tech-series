# MC-NET, the network terminal

MC-NET is the operating system of the network terminal. It is a Vintage system, made by Nouvell, and it needs 2 MB of RAM ([](jsc:eras)).

You install MC-NET from an install medium only, the way you install MC-DOS and UNIX System V ([](jsc:installing)).

With the Interactor installed, the Interactor takes the whole screen: the network's storage, its work and its prompt. Without it, MC-NET is only a prompt, the way a Linux with no desktop is only a prompt. The message on the screen names what is missing.

> [!DEFINE] MC-NET
> The Vintage operating system of the network terminal, which shows the Interactor on the whole screen.

> [!DEFINE] Operating space
> The full screen a system draws around its prompt, with its own store and work. A system with no operating space is only a prompt.

On a WAN Gateway Computer, Nouvell BorderLink brings an operating space of its own, which takes the screen in the Interactor's place: Ports, Log and Console on its rail ([](jsc:wan_gateways)).

## If something goes wrong

> [!PROBLEM] The screen is only a prompt.
> The Interactor is missing from MC-NET. Follow the message on the screen, which names what is missing and how to put it back.
