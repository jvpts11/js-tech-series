# A barra de tarefas e o seu menu

A barra de tarefas é a barra ao longo da parte inferior da tela. Ela tem o botão Iniciar, um botão para cada programa aberto e a área de status à direita. Toda edição do Frames tem uma barra de tarefas com 24 pixels de altura, mas cada uma tem uma aparência diferente.

Table: A barra de tarefas de cada edição

| Edição | Aparência da barra |
| --- | --- |
| Frames 95 | Uma barra cinza com bordas em relevo. Iniciar fica no canto esquerdo, cada programa aberto tem um botão com nome, e a área de status fica afundada à direita. |
| Frames XP | Uma barra com degradê azul, com a pílula verde Iniciar e uma faixa de inicialização rápida ao lado. |
| Frames 7 | Uma superbarra de ícones sem títulos. Cada programa é um botão de vidro com só o seu ícone. Um programa com várias janelas mostra a borda de um segundo painel atrás do seu. |
| Frames 10 | Uma barra escura: Iniciar, a caixa de pesquisa, o botão Exibição de Tarefas, um quadrado para cada programa, depois a área de status e o botão Central de Ações. |
| Frames 11 | Uma faixa escura e chapada. Iniciar e os ícones dos programas ficam juntos, centralizados. Cada ícone tem uma pequena marca que mostra o que o seu programa está fazendo. A barra não mostra títulos de janelas. |

## Clicando no botão de um programa

O que acontece depende do estado das janelas do programa.

Table: Um clique no botão de um programa

| Você clica em | O que acontece |
| --- | --- |
| Um programa que não está aberto | Ele inicia. |
| A janela única dele, em primeiro plano | A janela minimiza e desce para a barra de tarefas. |
| A janela única dele, minimizada | A janela volta. |
| A janela única dele, atrás de outras | A janela vai para o primeiro plano. |
| Várias janelas | Um pop-up lista as janelas daquele programa, para você escolher uma. |

## O menu de um programa aberto

Clique no botão de um programa com o botão direito para abrir o menu dele. Os itens que você vê dependem das janelas dele.

Table: O menu de um programa aberto

| Item | Quando aparece |
| --- | --- |
| Restaurar todas | O programa tem várias janelas. |
| Restaurar | A janela única dele está minimizada. |
| Trazer para frente | A janela única dele não está minimizada. |
| Minimizar todas | O programa tem várias janelas. |
| Minimizar | O programa tem uma janela. |
| Minimizar as outras | O programa está aberto. |
| Maximizar | O programa tem uma janela. |
| Fechar todas as janelas | O programa tem várias janelas. |
| Fechar | O programa tem uma janela. |
| Fixar na barra de tarefas, ou Desafixar da barra de tarefas | Todas as edições do Frames. Mantém o botão do programa na barra, mesmo quando o programa está fechado. |

Um programa fechado tem um menu mais curto: Abrir, e Desafixar da barra de tarefas se ele estiver fixado.

## O menu da barra vazia

Clique com o botão direito na parte vazia da barra para abrir o menu dela. Uma linha separa Mostrar a Área de Trabalho de Gerenciador de Tarefas.

Table: O menu da barra vazia

| Linha | O que faz |
| --- | --- |
| Janelas em Cascata | Organiza as janelas em cascata. |
| Mostrar a Área de Trabalho | Minimiza todas as janelas. |
| Gerenciador de Tarefas | Abre o Gerenciador de Tarefas. |

## A área de status

À direita da barra, a área de status mostra a rede, o som, a memória e o relógio, e em algumas edições o dia. A memória é a memória de acesso aleatório (RAM).

Table: A área de status

| Mostra | O que lê |
| --- | --- |
| A rede | "Rede conectada" ou "Sem rede". |
| A memória | "RAM" e a quantidade em uso. |
| O relógio | A hora: em 24 horas por padrão, ou em 12 horas se você escolher isso em Personalizar. |
| O dia | No Frames 7 e no Frames 10: o dia atual do jogo, abaixo da hora, marcado como "Day". |

## O Gerenciador de Tarefas

O [Gerenciador de Tarefas](jsc:task_manager) lista os programas em execução. Ele também mostra o processador, a memória, a rede e os discos, e finaliza um programa que deixa de responder. Suas páginas são Aplicativos, Processos, Desempenho, Rede, Serviços e Armazenamento.

O Frames 95 dá ao seu Gerenciador de Tarefas a forma de um botão de fechar. O Frames XP e o Frames 7 usam abas, e o Frames 10 e o Frames 11 usam uma forma moderna com gráficos.

> [!WARNING] Finalizar um programa pode causar a perda de trabalho não salvo.

## Se algo der errado

> [!PROBLEM] Uma janela desapareceu da tela.
> Ela está minimizada. Clique no botão dela na barra de tarefas para trazê-la de volta.

> [!PROBLEM] Um programa tem várias janelas e você não consegue saber qual delas quer.
> Clique no botão do programa e depois escolha a janela no pop-up.

> [!DEFINE] Exibição de Tarefas
> Uma visão do Frames 10 que escurece a área de trabalho e mostra cada janela aberta como um cartão.

> [!DEFINE] Central de Ações
> O painel escuro do Frames 10 que lista as notificações e reúne as ações rápidas.
