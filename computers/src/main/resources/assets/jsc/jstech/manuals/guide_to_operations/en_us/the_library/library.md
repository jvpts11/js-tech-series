# The library

A book is an item you can hold. The Guide to Operations is the first, and six more sit beside it: the Frames Resource Kit, The Linux Desk Reference, Linux by Hand, The Daemon Handbook, Learning IQL and The Book of Sigma. Each book opens its own manual when you use it, and each is written for one family of systems or one language.

A manual is one of these seven books, read as pages in the game. You turn its pages and find its chapters the same way you read this Guide.

You make this Guide at the Crafting Table, and a computer's help prints the other books at the Large Scale Printer ([](jsc:large_scale_printer)). In creative, the books are on the tab J's Computers, among the programs, beside this Guide.

When you open a computer's help, the system opens its own book first, and the other books follow in their order. The help of MC-NET opens the Guide to Operations.

Table: The first book of each system

| System | Book it opens first | Installed by |
| --- | --- | --- |
| MC-DOS | The Frames Resource Kit | Any install |
| Frames 95, XP, 7, 10 and 11 | The Frames Resource Kit | Any install |
| Ubuntu, Debian and Fedora | The Linux Desk Reference | A guided install |
| Arch Linux | Linux by Hand | Installing by hand from the live medium |
| Gentoo | Linux by Hand | Building from source |
| FreeBSD and UNIX | The Daemon Handbook | Any install |
| MC-NET | The Guide to Operations | Any install |

Every Linux install that is not guided opens Linux by Hand, which means Arch Linux and Gentoo.

Table: The six books

| Book | What it covers |
| --- | --- |
| Frames Resource Kit | MC-DOS and the Frames editions, from Frames 95 to Frames 11. |
| The Linux Desk Reference | Fedora, Debian and Ubuntu, and the shell, desktops, editors and help they share with the other UNIX books. |
| Linux by Hand | Installing Arch Linux and Gentoo by hand, one step at a time. |
| The Daemon Handbook | FreeBSD and UNIX System V. |
| Learning IQL | The network's query language, its engines and its tools. |
| The Book of Sigma | Sigma and Sigma#, their library and their tools. |

## If something goes wrong

> [!PROBLEM] The help opened a book you did not expect.
> The system and its install choose the first book, and you cannot change that. The other books still follow in their order.

> [!PROBLEM] You cannot find a book.
> Open the creative tab J's Computers and look among the programs, beside the Guide.
