# O Midsoft Lithography no prompt

O Midsoft Lithography é o programa de um computador ligado por cabo a uma Estação de Litografia da Legacy em diante: mostra a estação e grava as máscaras pelas quais ela expõe ([](jsc:mask_writing)). No desktop ele abre como uma janela. Num terminal, digite litho e ele ocupa a tela inteira.

1. Ponha uma Máscara Virgem na estação.
2. Digite litho e aperte [[Enter]].
3. Aperte [[Tab]] até o tipo de chip que você quer ficar aceso, e escolha a sua máscara com as setas para cima e para baixo.
4. Aperte [[W]] para gravar a máscara na máscara virgem e depois [[F3]] para devolver o terminal.
