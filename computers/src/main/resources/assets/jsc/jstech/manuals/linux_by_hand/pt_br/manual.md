# Linux à Mão

Este caderno guia você na instalação do Gentoo e do Arch Linux à mão, do jeito que eles são realmente instalados: você digita cada passo, e o livro explica o que cada um faz.

Seus últimos capítulos são o shell, as áreas de trabalho, os editores e como encontrar ajuda, do mesmo jeito que nos outros livros desses sistemas.

Uma bandeira de papel na borda das páginas abre cada capítulo.
