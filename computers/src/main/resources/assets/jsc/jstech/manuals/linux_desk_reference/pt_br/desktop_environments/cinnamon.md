# Cinnamon

Cinnamon é uma área de trabalho da Spearmint Linux, uma software house do mundo do mod. Ela roda em Linux e FreeBSD, e precisa de hardware Standard ou mais recente. É uma área de trabalho mais nova, então nenhum computador mais antigo consegue rodá-la.

Cinnamon tem uma só aparência, em todo computador em que roda, então você nunca encontra um rosto mais antigo. O seu pacote se chama cinnamon.

O menu tem três partes: uma coluna à esquerda com os favoritos, depois as categorias, depois a lista de programas da categoria escolhida. As categorias são Sistema, Acessórios, Escritório e Preferências.

Table: As categorias

| Categoria | O que contém |
| --- | --- |
| Sistema | Arquivos, Este Computador, o Monitor do Sistema, o Prompt de Comando, a Rede, a Ajuda e as demais ferramentas do sistema |
| Acessórios | Todo o resto: a Calculadora, os editores, os jogos |
| Escritório | Exceed, o Workshop, o Gerenciador de Fabricação, o Pattern Studio, o Planejador de Fabricação, a Análise de Armazenamento e o Gerenciador de Automação |
| Preferências | Configurações |

Cinnamon dá aos seus programas nomes próprios: Nemo para Arquivos, xed para o Editor, Terminal para o Prompt de Comando, Configurações do Sistema para Configurações e Informações do Sistema para Este Computador. A lista completa está em [](jsc:desktop_program_names).

Para instalá-lo, use o formulário do seu sistema em [](jsc:install_a_desktop). As linhas de inicialização mostram "Iniciando cinnamon Gerenciador de exibição".

## Se algo der errado

> [!PROBLEM] O gerenciador de pacotes diz "cinnamon precisa de hardware Standard ou mais recente".
> O computador é mais antigo que Standard. Use um computador Standard ou mais novo.

> [!PROBLEM] O instalador não oferece Cinnamon em um computador Legacy.
> Em um computador Legacy, escolha outra área de trabalho, porque o Cinnamon é oferecido apenas em hardware Standard ou posterior.
