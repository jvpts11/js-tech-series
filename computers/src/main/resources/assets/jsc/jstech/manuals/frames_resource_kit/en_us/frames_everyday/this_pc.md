# This PC

This PC is the window that shows the machine itself: its name, its disks, the drives linked to it, the hardware seated in it and the programs installed on it. Open it when you want to know what the computer holds. On Frames 7 the same window is called Computer.

## The card at the top

The top of the window is a card for the machine. It shows the machine's name, its kind, its era, its system and whether it is on a network. A machine with no system says "No system installed".

## Renaming the machine

You can give the machine a name of your own. The name can be 32 characters long at most, and the machine trims the spaces at both ends before it keeps the name.

1. Press Rename on the card.
2. Type the new name in the field.
3. Press [[Enter]] to save the name.

A disk or medium has a name too. Select its row and press Rename: the name is cut to 32 characters, and a blank name is ignored.

## Devices and drives

Under the card, Devices and drives lists each disk with a bar that shows how full it is, and the system it holds. Each linked drive names what is in it. For an installer, the row says what it would install.

Table: Buttons on a row

| Button | What it does |
| --- | --- |
| `Open` | Opens the disk or medium in the Files window ([](jsc:file_explorer)). |
| `Install` | Starts an install from an installer medium ([](jsc:installing)). |
| `Eject` | Takes the medium out of the drive ([](jsc:drives)). |

Install appears only on an installer. Eject appears only on a drive that holds a medium.

Further down, the window lists the hardware seated in the machine. Installed programs follows, as a grid of the programs on the machine.

> [!DEFINE] Device
> A piece of hardware attached to the machine, such as a drive or a monitor.

> [!DEFINE] Volume
> The name a disk or medium carries. This PC and the Files tree show it.

## If something goes wrong

> [!PROBLEM] The window says "No disks installed and no drives linked".
> Install a disk in the computer, or link a drive to it ([](jsc:drives)).

> [!PROBLEM] The window says "No system installed".
> Install a system first ([](jsc:installing)).

> [!PROBLEM] The name does not change after you press Enter.
> The field was blank once its spaces were trimmed, and a blank name is ignored. Type a name.

> [!PROBLEM] You cannot type more than 32 characters.
> The field stops at 32 characters. Use a shorter name.

> [!SEE] jsc:drives, jsc:installing
