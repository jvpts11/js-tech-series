# Catalogue

Every part J's Computers has, era by era, with the figures the game works from. This page is generated from the
code that declares the parts, so it always matches the mod. A processor's capacity and a graphics card's power
are in items per tick, worked out with the formulas in [Hardware](hardware.md); a memory module's buffer is its size
at 4 MB per item; a disk's room is in items, at the item size of its era ([Storage devices](storage-devices.md)).

In all: 173 processors, 51 motherboards, 30 memory modules, 76 graphics and compute cards,
5 sound cards, 12 power supplies and 26 disks. The compute cards are marked; they belong to the AI
([Artificial intelligence](ai.md)).
