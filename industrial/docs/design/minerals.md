# Minerals

Every mineral of the Overworld, element by element: about 250 of them. Each is a real ore mineral, with its formula, the
setting it typically belongs to, and the byproducts it gives when it is processed (in fixed proportions, decided with
the machines). How minerals, "X ores" and host rocks work is in [Materials](materials.md); how they are grouped into
veins is in [The world](world.md).

The list reflects the Earth. Every planet of J's Space has mineral families of its own in the same registries: Mars need
not mirror the Overworld. Nothing on this page exists yet: it is all to build.

## To build

**"X ore"** marks the generic ore of the element ([Materials](materials.md)): vanilla's for iron, copper and gold, J's
Core's for the others. **No X ore** marks the elements whose minerals are their only ores.
