# J's Space documentation

The documentation of J's Space, the space mod of the J's Tech Series: rockets, satellites, the worlds of the Solar
System and of other stars, and the starships that reach them. None of it is built yet, so for now its documentation is
its design; the pages for players and for mod authors come with the code.

## The design

[The design of J's Space](design/README.md): one page per subject, from the universe and its worlds to rockets, travel,
life support, satellites, exploration, starships, the ruins of older civilizations and the great works, saying how
every system works and why, with the order in which it will be built.
