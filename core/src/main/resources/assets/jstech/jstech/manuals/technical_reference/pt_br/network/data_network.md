# A rede

## O que é

A rede são computadores ligados por cabos de dados em volta de um computador grande, o Mainframe. Cada rede tem exatamente um Mainframe, e toda máquina nela leva o nome dele.

## Para que serve

Uma rede guarda itens como dados nos seus discos, devolve quando pedidos, leva-os entre máquinas e fabrica para você. Máquinas de outros mods da série entram nela pelos mesmos cabos.

> [!DEFINE] Operação
> Um pedido que a rede cumpre: guarde isto, me dê aquilo, fabrique isto. Cada um espera numa fila do Mainframe até ficar pronto.

## Como conseguir

Monte um Mainframe do J's Computers e passe cabos de dados dele até as máquinas que devem entrar.

## Como usar

1. Monte o Mainframe e dê a ele as suas peças.
2. Passe cabo de dados dele até um Rack de Servidores com servidores e discos, onde os itens ficam guardados.
3. Ligue um computador à rede e abra o programa Rede dele para pôr e tirar itens.

## O que pode dar errado

> [!PROBLEM] Dois Mainframes, e nada funciona.
> Uma rede tem um Mainframe. Separe os cabos, para que cada Mainframe tenha a sua própria rede.
