# Gas Cylinder

## What it is

A slim steel cylinder with a bronze valve that carries one gas by hand, as a bucket carries a fluid: 10,000 mB, 50 litres at 200 times the open air's pressure, one cylinder to a stack. Its shoulder is painted the colour the European code gives the gas inside, and an empty one shows its bare steel.

Table: Shoulders by the European code

| Property | Value |
| --- | --- |
| Chlorine, fluorine | Yellow: toxic and corrosive |
| Argon | Dark green |
| Hydrogen | Red: flammable |
| Oxygen | White |
| Nitrogen | Black |
| Krypton, neon, xenon | Bright green: inert |
| Helium | Brown |
| Carbon dioxide | Grey |

A gas the code does not name shows its own colour.

## What it is for

Carrying a gas by hand from where it is made to where it is used, and naming a gas wherever one is chosen, as a bucket names a fluid.

## How to get it

Craft it from seven steel plates round the sides and the bottom and a bronze ingot on top, its valve.

## How to use it

1. Its shoulder and its tooltip say which gas it holds, and its tooltip's bar how full it is.

## What can go wrong

> [!PROBLEM] The shoulder shows a colour the table does not list.
> The gas inside is one the European code does not name: the shoulder takes the gas's own colour.
