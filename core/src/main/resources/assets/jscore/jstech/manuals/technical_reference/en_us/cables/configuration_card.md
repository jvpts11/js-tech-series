# Configuration Card

## What it is

A card that remembers how a machine is set up.

## What it is for

Setting up many machines alike: a row of furnaces, a wall of crushers.

Table: What it carries

| Property | Value |
| --- | --- |
| Sides | What each face does with each resource, and what the machine pushes and pulls by itself, through which filter |
| Redstone | How the machine answers redstone, and what a comparator reads of it |
| Locks and recipe | Its input slots' locks and the recipe picked, for a machine of the same kind only |

## How to get it

Craft it of a sheet of paper, a redstone dust and a gold nugget.

## How to use it

1. Sneak and use it on a machine to copy its setup.
2. Use it on another machine to paste it: whole into one of the same kind, what fits into another.
3. Use it on a block that is not a machine, then on the opposite corner of a box: every machine in the box takes the setup at once.
4. Sneak and use it anywhere else to blank it.

## What can go wrong

> [!PROBLEM] A machine takes nothing.
> It is someone else's, or it has none of the resources copied: copy from a machine of the same kind.

> [!PROBLEM] Pasting over a box does nothing.
> The box holds more than 4,096 blocks: mark a smaller one.
