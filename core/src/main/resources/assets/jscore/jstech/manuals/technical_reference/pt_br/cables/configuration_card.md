# Cartão de Configuração

## O que é

Um cartão que lembra como uma máquina está configurada.

## Para que serve

Configurar muitas máquinas iguais: uma fila de fornos, uma parede de trituradores.

Table: O que ele leva

| Propriedade | Valor |
| --- | --- |
| Lados | O que cada face faz com cada recurso, e o que a máquina empurra e puxa sozinha, por qual filtro |
| Redstone | Como a máquina responde à redstone, e o que um comparador lê dela |
| Travas e receita | As travas das entradas e a receita escolhida, só para uma máquina do mesmo tipo |

## Como conseguir

Faça-o com uma folha de papel, um pó de redstone e uma pepita de ouro.

## Como usar

1. Agache e use-o numa máquina para copiar a configuração dela.
2. Use-o em outra máquina para colar: inteira numa do mesmo tipo, o que servir em outra.
3. Use-o num bloco que não é máquina e depois no canto oposto de uma caixa: toda máquina da caixa recebe a configuração de uma vez.
4. Agache e use-o em qualquer outro lugar para apagá-lo.

## O que pode dar errado

> [!PROBLEM] Uma máquina não recebe nada.
> É de outra pessoa, ou não tem nenhum dos recursos copiados: copie de uma máquina do mesmo tipo.

> [!PROBLEM] Colar numa caixa não faz nada.
> A caixa tem mais de 4.096 blocos: marque uma menor.
