# Este manual

## O que é

A Referência Técnica: o fichário que traz um capítulo para cada mod da série que você tem, cada um com a sua aba na borda.

## Para que serve

Descobrir o que uma coisa é e como usá-la, sem sair do jogo.

## Como conseguir

Você ganha um na primeira vez que entra num mundo. Há outro na aba criativa J's Core.

## Como usar

1. Use o manual para abri-lo na capa; clique para abrir.
2. Clique numa linha do sumário, numa aba, ou num número depois de Veja para ir até lá.
3. Vire as páginas com as setas, as teclas de seta ou a roda do mouse.
4. Use a lupa na borda de cima para buscar no índice pelo nome.
5. Segure a tecla do manual sobre qualquer item, num inventário ou na mão, para abrir a página dele.
6. Aperte a folha na borda de cima para arrancar uma cópia da página da esquerda; numa moldura, a folha mostra a página.
7. Use-o num atril para deixá-lo lá, para quem passar ler.

## O que pode dar errado

> [!PROBLEM] Um item não abre nenhuma página.
> Nenhum manual tem uma entrada para ele ainda.

> [!PROBLEM] Falta um capítulo.
> O mod dele não está instalado: o fichário traz os mods que você tem.
