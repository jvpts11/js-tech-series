# O bloco de cabos

## O que é

Um bloco em que todo mod da série passa os seus cabos. Cada tipo de cabo corre numa faixa própria, então cabos de mods diferentes dividem um bloco sem se tocar.

## Para que serve

Passar energia, dados e os cabos periféricos dos computadores pelo mesmo espaço, cada um na sua linha.

## Como conseguir

Pegue um cabo na aba criativa de um mod: o Cabo de Energia do J's Industrial, os cabos de dados e periféricos do J's Computers.

## Como usar

1. Coloque um cabo como se coloca um bloco.
2. Coloque um cabo de outro tipo no mesmo bloco: ele ocupa a sua própria faixa.
3. Quebre o bloco para pegar os cabos de volta, cada um como um item.

## O que pode dar errado

> [!PROBLEM] Dois cabos lado a lado não se ligam.
> Só cabos da mesma linha se ligam. Um cabo de energia nunca se liga a um cabo de dados, nem no mesmo bloco.
