# Veículos

## O que é

Todo veículo dos mods e data packs que você tem: cada um colocado a partir de um item Veículo que diz o seu tipo, e feito de peças, cada uma um item Peça de veículo enquanto está fora de um.

## Para que serve

Viajar e carregar: os assentos levam jogadores e robôs, e quem senta num assento de motorista o dirige.

## Como conseguir

Como diz o mod ou o data pack que traz o veículo. No criativo, a aba Ferramentas e utilidades tem todo tipo e toda peça.

## Como usar

1. Use o item no chão para colocar o veículo ali, virado para onde você olha: ele é seu, e a chave dele é cortada para você quando o tipo tem chaves.
2. Use o veículo para entrar; num assento de motorista, as teclas de andar o dirigem, enquanto ele queima o combustível ou puxa da bateria.
3. Use uma peça no veículo perto do lugar vazio daquele tipo para encaixá-la; agache com uma chave inglesa para tirar uma, ou segure o material dela na outra mão para consertar uma gasta.
4. Use um corante nele para pintá-lo, e a chave dele com a tecla de agachar segurada para trancá-lo ou destrancá-lo.
5. Agache com a mão vazia perto do engate para engatar um reboque nele, ou para soltá-lo.
6. Bata nele para desfazê-lo no item, que guarda as peças, o combustível e a carga, e o coloca de novo como estava.

## O que pode dar errado

> [!PROBLEM] Ele não anda.
> O combustível ou a bateria acabou, ou falta uma peça de que ele precisa, ou ela está gasta.

> [!PROBLEM] Não dá para mudá-lo nem desfazê-lo.
> Ele é de outra pessoa: só o dono e quem ele confia podem configurá-lo.
