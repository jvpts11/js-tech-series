# Serra e microblocos

## O que é

Uma lâmina de ferro num cabo de madeira, a serra partilhada da série, e os microblocos que ela corta: peças de qualquer bloco inteiro, de qualquer mod.

## Para que serve

Construir com peças menores que um bloco e vestir cabos: várias peças, cabos e as partes neles dividem um mesmo espaço de bloco.

Table: As peças

| Propriedade | Valor |
| --- | --- |
| Laje, painel, cobertura | Metade, um quarto e um oitavo de bloco contra uma face, e as espessuras entre elas |
| Oca | Uma peça numa face com um furo no meio, pelo qual um cabo continua ligado |
| Poste | Uma barra ao longo de uma aresta do bloco, ou pelo seu meio |
| Canto | Um cubo num canto do bloco |
| Fachada | Uma cobertura junta com um cabo: esconde o cabo atrás dela, que continua funcionando |

Table: Onde a serra fica na grade de fabricação

| Propriedade | Valor |
| --- | --- |
| Acima da peça | Duas metades: um bloco dá duas lajes, uma laje dois painéis, um painel duas coberturas |
| Ao lado dela | Corte transversal: uma peça numa face dá dois postes, um poste dois cantos |
| Num canto dela | Vazada: uma peça numa face dá uma com um furo |

## Como conseguir

Fabrique a serra com um graveto e dois lingotes de ferro em fila. Cada corte a gasta um pouco, e ela fica na grade.

## Como usar

1. Coloque uma peça contra a face de um bloco para pô-la no espaço além dela; coloque-a no lado de uma peça que já está num espaço para pô-la nesse mesmo espaço.
2. Um poste vai na aresta mais perto de onde você clica, ou pelo meio quando você clica perto do meio da face; um canto, no canto mais próximo.
3. Duas peças de uma forma e de um bloco, lado a lado na grade, juntam-se numa tão grossa quanto as duas; duas lajes refazem o bloco.
4. Junte uma cobertura com um pedaço de qualquer cabo para fazer uma fachada, e coloque-a na face de um cabo.
5. Quebre uma peça para tirar só ela, com o que ela dropa; as outras ficam.

## O que pode dar errado

> [!PROBLEM] Uma peça não é colocada.
> Algo já ocupa esse lugar, ela se sobreporia a uma peça ali ou entraria num cabo, ou alguém está de pé nele. Num cabo, use uma cobertura, um painel ou uma peça oca.

> [!PROBLEM] Um cabo deixa de se ligar por uma face.
> Uma cobertura inteira fecha a face; use ali uma oca ou uma fachada.
