# Ferramenta de Física

## O que é

Uma ferramenta de metal escuro com três garras em volta do emissor, que move estruturas móveis com a mão.

## Para que serve

Pôr uma estrutura móvel onde você quer: levantá-la, empurrá-la, ou segurá-la parada no ar.

Table: Os modos

| Propriedade | Valor |
| --- | --- |
| Agarrar | Segura o ponto mirado à sua frente enquanto você anda e olha, como uma mola firme que aguenta o peso |
| Empurrar | Dá um golpe nela onde ela é mirada |
| Congelar | Segura-a onde ela está, no ar também, até ser solta de novo |

## Como conseguir

Fabrique-a com uma magnetita no meio, um lingote de ferro de cada lado dela, e um fragmento de ametista e um pó de redstone em dois cantos opostos. Um servidor pode desligar a receita.

## Como usar

1. Mire numa estrutura móvel e segure o botão de usar para agir nela no modo da ferramenta.
2. Gire a roda do mouse para trocar o modo, e com Shift a força, de um décimo ao todo: o quanto ela segura e empurra.

## O que pode dar errado

> [!PROBLEM] Nada se move.
> A ferramenta só move estruturas móveis. Uma pesada pede mais força: aumente-a.
