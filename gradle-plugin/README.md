# J's Core's Gradle plugin

`dev.jstech.core`: a mod built on J's Core applies it beside ModDevGradle and gets the Core as a dependency, a
source set for its tests with the Core's test kit, its development runs, the data generation and its check, the
check of its API against its photo, and its licence headers.

Published to the local Maven repository for now: `./gradlew :gradle-plugin:publishToMavenLocal`.

How to use it: [core/docs/GRADLE_PLUGIN.md](../core/docs/GRADLE_PLUGIN.md).
